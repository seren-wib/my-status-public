# 자격증 파일 형식

> 2026-08-26 확정. 로드맵 md와 **다른 양식** — 체크박스가 아니라 카드 목록이다.

```
certifications/
├── index.json          분야 목록 (파서 생성)
├── <분야>.md           원본. 분야당 1파일
└── <분야>.json         파서 산출물 (손대지 말 것)
```

## 왜 로드맵 양식이 아닌가

자격증엔 **진행률이 없다.** 합격 아니면 미합격이고, 공부 진도는 이미 로드맵이 세고 있다.
체크박스로 두면 같은 공부가 분모에 두 번 들어가 스탯이 오염된다 — 그래서 자격증은
`roadmaps/` 밖에 있고 파서·`build_stats.py`가 안 훑는다. `milestones/`와 같은 취급.

- **딸 수 있는 것** = 이 파일 (지도)
- **딴 것** = `data/inventory.json`의 `certifications` (결과, INVENTORY 소관)
- 둘은 `id`로 붙는다. 이름 문자열 대조 금지 — 표기가 흔들린다(`정보처리기사` ↔ `기사(정보처리)`)

## 골격

```
# <분야 한글 이름> 자격증

> 2026-08-26 · 응시자격·일정은 주관처가 수시로 바꿈. 원서 전 공식 사이트 확인

## <분류>                    ← H2. 국가기술자격 · 국가공인민간자격 · 글로벌 벤더 인증 등

### <자격증 이름> `<id>`      ← H3. id는 kebab-case, 파일 전체에서 유일
- 발급: <주관처>
- 지역: 국내 | 해외
- 조건: <응시자격. 제한 없으면 "제한 없음">
- 시험: <구성 · 시행 주기>
- 갱신: <유효기간. 평생이면 "없음">
- 로드맵: `<경로>` `<경로>`     ← roadmaps/ 기준, 확장자 없음. 여러 개면 백틱 나열
- 비고: <선택. 없으면 줄 자체를 뺌>
```

- 키는 위 7개 고정. 값은 콜론 뒤 한 줄 — 파서가 `- 키: 값`으로 자름
- `로드맵`은 **prefix 매칭용 경로**다. 로드맵 하나를 콕 집어도 되고 폴더를 가리켜도 됨
  (`software/skill-based/Infra-DevOps` = 그 폴더 전체). 로드맵 경로 규칙은 저장소 전체와 동일
- 분야에 딸 자격증이 없으면 **파일을 만들지 않는다** (social·meta). 빈 파일은 없는 것과 같음

## 무엇을 싣는가 (격자)

**싣는 것** — 국가기술자격 · 국가전문자격 · 국가공인 민간자격 · 공인 어학시험 ·
글로벌 벤더/재단 공식 인증(AWS·CNCF·CFA Institute 등). 국내·해외 구분 없이 실음(2026-08-26 사용자 지시).

**안 싣는 것**
- 비공인 민간자격 — 국내 등록민간자격만 수만 개고 채용에서 안 쳐줌. 공인 여부가 유일한 잣대
- 학위·전공이 응시 요건의 전부인 것(간호사·영양사) — 딸 수 있는 게 아니라 진학 문제.
  단 **전공 요건이 있어도 그 전공에 있으면 딸 수 있는 것**(임상심리사·건강운동관리사)은 조건을 적어 실음
- 사양된 종목(전자계산기조직응용기사류) · 시험이지 자격이 아닌 것(TOPCIT·모의고사)
- **비용** — 응시료는 매년 바뀌고 감면 제도가 갈려 적으면 바로 낡는다. 공식 사이트가 원본

## 변환

`python tools/parse_certs.py` → `certifications/<분야>.json` + `index.json`.
md를 고치면 재실행. 로드맵 파서와 별개 스크립트다(양식이 다르므로).

json 한 장:

```json
{"domain": "software", "title": "소프트웨어 자격증", "count": 26,
 "categories": [{"title": "국가기술자격",
   "certs": [{"id": "engineer-information-processing", "name": "정보처리기사",
              "issuer": "한국산업인력공단", "region": "국내", "eligibility": "...",
              "exam": "...", "renewal": "없음", "note": null,
              "roadmaps": ["software/role-based/backend"]}]}]}
```

## 프론트에서의 쓰임

"딸 수 있는 자격증" 화면 = `<분야>.json` + `data/stats.json`(또는 로드맵 json+log).
`roadmaps` 경로를 진행도에 prefix 매칭해 **관련 로드맵이 얼마나 찼는지**를 옆에 띄운다.
합격 여부는 `inventory.json`의 `id`로 대조 — 있으면 획득 표시, 없으면 후보.
진행률을 자격증 자체에 붙이지 말 것(위 "왜 로드맵 양식이 아닌가").
