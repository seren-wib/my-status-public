# Reading and Notes `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-26

## 1. Reading Modes

- [ ] Inspectional Read / 목차·서문·결론만 훑어 30분 안에 구조 파악
- [ ] Analytical Read / 저자의 주장·근거·전제를 한 장으로 재구성
- [ ] Syntopical Read / 같은 주제 자료 3종 이상 놓고 쟁점표 만들기
- [ ] Abandonment Rule / 계속 읽을 값어치 판정 기준 정하고 실제로 한 권 중단
- [ ] Source Ladder / 대중서→교과서→원논문 순으로 같은 주제의 층위 올리기

## 2. Extraction

- [ ] Concept Naming / 문단을 개념 이름 하나로 압축해 적기
- [ ] Quote versus Paraphrase / 인용과 내 말 구분 표기 규칙 고정
- [ ] Claim and Evidence / 근거 링크가 없는 노트를 걸러내기
- [ ] Progressive Summarization / 원문→요약→핵심 3단으로 재압축

## 3. Note System

- [ ] Atomic Note / 노트 하나에 개념 하나로 쪼개기
- [ ] Link Density / 새 노트를 기존 노트 둘 이상에 연결
- [ ] Index Entry / 진입점 노트 만들어 주제별로 색인
- [ ] Naming Convention / 제목 규칙 정해 검색 가능하게 유지
- [ ] Orphan Sweep / 연결 0인 노트 정리 주기 돌리기

## 4. Feedback into Practice

- [ ] Note to Card / 노트에서 인출 카드 뽑아 덱에 투입
- [ ] Note to Roadmap / 읽다 발견한 결핍을 내 로드맵 항목으로 추가
- [ ] Write to Check / 노트만 보고 한 편 써서 구멍 드러내기
- [ ] Input Output Ratio / 읽은 것 대비 남은 산출물 비율 산출
