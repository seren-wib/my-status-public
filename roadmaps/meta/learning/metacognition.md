# Metacognition `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-26

## 1. Calibration

- [ ] Confidence Rating / 문제마다 확신도 적고 정답과 대조
- [ ] Calibration Curve / 확신도 구간별 실제 정답률 그려 과신 폭 확인
- [ ] Brier Score / 내 예측 20건 이상으로 점수 계산해 기준선과 비교
- [ ] Overconfidence Correction / 과신 구간에 보정치 걸고 재측정

## 2. Illusions of Learning

- [ ] Fluency Illusion / 재독 뒤 안다는 느낌과 실제 인출 성적의 괴리 실측
- [ ] Judgment of Learning / 학습 직후 예상 점수와 지연 시험 점수 비교
- [ ] Highlighting Audit / 밑줄만 그은 자료의 회상률 확인
- [ ] Hindsight Check / 답 본 뒤 '알고 있었다'는 감각을 기록으로 반증

## 3. Study Regulation

- [ ] Time Allocation Check / 어려운 항목에 실제로 시간이 갔는지 세션 로그로 확인
- [ ] Stop Rule / 언제 그만 볼지 기준을 느낌이 아니라 성적으로 정하기
- [ ] Method Comparison / 같은 분량을 두 방법으로 나눠 지연 시험으로 비교
- [ ] Prior Knowledge Baseline / 시작 전 아는 것 백지에 적어 기준선 남기기

## 4. Depth of Understanding

- [ ] Explain Without Notes / 자료 없이 설명하고 막힌 지점 표시
- [ ] Self-Explanation / 풀이 각 줄이 왜 그런지 스스로 설명
- [ ] Question Generation / 자료로 시험 문제 직접 출제해 풀어보기
- [ ] Transfer Probe / 배운 개념을 다른 분야 사례에 적용해보기

## 5. Failure Analysis

- [ ] Error Taxonomy / 오답을 개념·부주의·전략으로 분류해 비율 산출
- [ ] Learning Post-mortem / 무너진 학습 시도의 전말 기록
- [ ] Learning Styles Claim / 학습 유형 맞춤 주장의 반증 근거 확인
