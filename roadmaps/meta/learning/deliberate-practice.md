# Deliberate Practice `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-26

## 1. Target Selection

- [ ] Skill Decomposition / 한 기술을 30분 안에 반복 가능한 하위 동작으로 분해
- [ ] Weakness Isolation / 실패 지점만 뽑아 전용 드릴 만들기
- [ ] Performance Metric / 드릴마다 숫자 지표 하나 붙여 매 세션 기록
- [ ] Edge of Ability / 성공률 70~85% 구간이 되게 난이도 조정

## 2. Feedback Loop

- [ ] Immediate Feedback / 정오를 즉시 아는 채점 경로 확보
- [ ] Error Log / 틀린 유형별로 세고 상위 3개만 다음 세션 과제로
- [ ] Recording Review / 내 수행을 녹화·저장해 사후 관찰
- [ ] Expert Comparison / 숙련자 수행과 내 것을 나란히 놓고 차이를 이름으로 적기
- [ ] Coaching Substitute / 채점 기준표·리뷰 요청·자동 검증으로 코치를 대신하는 경로

## 3. Mental Representation

- [ ] Chunking / 개별 동작이 한 덩어리로 자동화된 지점 표시
- [ ] Pattern Vocabulary / 반복되는 상황 패턴에 이름 붙여 목록화
- [ ] Anticipation Test / 다음 수를 먼저 적고 실제 전개와 대조

## 4. Load and Plateau

- [ ] Plateau Diagnosis / 지표 정지 원인을 난이도·피드백·반복량으로 분리
- [ ] Constraint Variation / 제약 하나 바꿔 같은 과제 재수행
- [ ] Session Length / 집중이 유지되는 세션 길이 실측해 상한 고정
- [ ] Effective Repetition Count / 누적 시간 대신 유효 반복 수로 기록
- [ ] Ten Thousand Hour Claim / 시간 총량설의 원 논문과 통속 해석 차이 확인

## 5. Skill Retention

- [ ] Spaced Skill Review / 안 쓰는 기술의 재수행 주기 정하기
- [ ] Rust Check / 3개월 미사용 기술 재측정해 감소폭 기록
- [ ] Transfer Test / 훈련하지 않은 변형 과제에서 성적 확인
