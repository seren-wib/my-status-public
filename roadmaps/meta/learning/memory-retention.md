# Memory Retention `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-26

## 1. Retrieval Practice

- [ ] Active Recall Conversion / 내 노트 한 챕터를 질문 카드로 뒤집어 재구성
- [ ] Testing Effect / 같은 분량을 재독 조건·인출 조건으로 나눠 1주 뒤 정답률 비교
- [ ] Free Recall Dump / 자료 덮고 백지에 쏟은 뒤 누락분만 표시해 회수
- [ ] Cue Leakage / 카드 앞면이 답을 흘리는지 점검해 재작성
- [ ] Desirable Difficulty / 너무 쉬운 카드 난이도 올려 목표 정답률까지 낮추기

## 2. Spacing Schedule

- [ ] Forgetting Curve / 내 항목 1일·3일·7일 지연 정답률 찍어 곡선 그리기
- [ ] Expanding Interval / 성공은 간격 증가·실패는 축소 규칙을 내 덱에 설정
- [ ] Desired Retention / 목표 파지율 정하고 복습량과의 교환 확인 (기본 90%)
- [ ] Scheduler Parameters / 내 리뷰 로그로 SM-2·FSRS 간격을 조정하고 부하를 재는 방법
- [ ] Queue Overload / 일일 복습 큐가 감당 못 하게 쌓인 원인 진단하고 신규 유입 상한 설정

## 3. Item Design

- [ ] Minimum Information Principle / 한 카드 한 사실로 쪼개 실패율 낮추기
- [ ] Cloze Deletion / 문장 빈칸형으로 바꿔 문맥 유지한 채 인출
- [ ] Interference Pair / 서로 헷갈리는 항목쌍 찾아 대조 카드로 분리
- [ ] Leech Handling / 반복 실패 항목 격리해 재설계하거나 폐기
- [ ] Mnemonic Anchor / 임의적 사실을 연상·기억궁전에 묶기

## 4. Practice Structure

- [ ] Interleaving / 유형 섞어 풀고 블록 연습 대비 지연 성적 비교
- [ ] Generation Effect / 답 보기 전 먼저 추측해 적기
- [ ] Elaborative Interrogation / '왜 그런가' 자문으로 기존 지식과 연결
- [ ] Dual Coding / 도식과 문장을 함께 남겨 인출 경로 둘로

## 5. Retention Audit

- [ ] Retention Check / 30일 지난 항목 무작위 20개 재시험해 실제 파지율 산출
- [ ] Review Load Budget / 일일 복습 시간 상한 정하고 덱 크기 역산
- [ ] Deck Retirement / 파지 안정된 항목 덱에서 내리는 기준 확정
