# Habit Formation `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-26

## 1. Behavior Model

- [ ] Cue Routine Reward / 만들 습관의 세 요소를 각각 문장으로 명시
- [ ] Motivation Ability Prompt / 실패한 날 셋 중 무엇이 빠졌는지 판정
- [ ] Ability over Motivation / 의욕을 올리는 대신 난이도를 낮춰 재시도
- [ ] Identity Statement / 무엇을 하는 사람인지의 문장으로 목표 재작성

## 2. Design

- [ ] Implementation Intention / 언제·어디서·무엇을 if-then 문장으로 고정
- [ ] Habit Stacking / 이미 굳은 습관 뒤에 새 행동 붙이기
- [ ] Two Minute Version / 2분 안에 끝나는 최소 버전으로 축소해 착수
- [ ] Environment Placement / 필요한 물건을 행동 경로 위에 배치
- [ ] Temptation Bundling / 하고 싶은 것과 해야 할 것 묶기

## 3. Reinforcement

- [ ] Immediate Reward / 행동 직후 보상을 붙여 강화 지연 없애기
- [ ] Reinforcement Schedule / 고정·변동 강화의 차이를 내 습관에 적용
- [ ] Satisfaction Signal / 완료 표시를 눈에 보이게 남기기
- [ ] Reward Conflict / 보상이 습관 목적을 무효화하는 경우 점검

## 4. Formation Period

- [ ] Automaticity Rating / 매주 자동성 자기평가 점수 남기기
- [ ] Formation Time / 자동성이 붙은 시점을 기록해 중앙값 66일과 대조하는 방법
- [ ] Context Stability / 장소·시간이 흔들릴 때 유지율 확인
- [ ] Missed Day Effect / 하루 거른 뒤 자동성 변화 관찰
