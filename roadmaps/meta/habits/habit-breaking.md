# Habit Breaking `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-26

## 1. Diagnosis

- [ ] Trigger Log / 끊을 행동의 계기·시각·상태를 2주 기록
- [ ] Craving Curve / 충동의 상승과 소멸까지 걸리는 시간 재기
- [ ] Functional Analysis / 그 행동이 대신 해주던 기능을 이름 붙여 명시
- [ ] Baseline Frequency / 개입 전 빈도를 수치로 확보

## 2. Friction

- [ ] Friction Addition / 실행까지 단계를 늘려 접근 비용 올리기
- [ ] Cue Removal / 계기를 환경에서 아예 제거
- [ ] Access Delay / 10분 지연 규칙 걸고 실행률 변화 기록
- [ ] Commitment Device / 차단 앱·예치·공개 선언으로 되돌리기 어렵게 만드는 장치

## 3. Substitution

- [ ] Replacement Behavior / 같은 계기에 다른 행동 배치
- [ ] Urge Surfing / 충동을 실행 없이 통과시키고 지속 시간 기록
- [ ] If-Then Escape / 위험 상황용 대응 문장 미리 작성

## 4. Relapse

- [ ] Lapse versus Relapse / 1회 실수와 복귀 실패를 구분해 기록
- [ ] Abstinence Violation Effect / 한 번 어긴 뒤 포기로 번지는 반응 관찰
- [ ] Extinction Burst / 차단 직후 빈도가 치솟는 구간 확인하고 통과
- [ ] High Risk Situation List / 재발한 상황 목록화해 사전 차단

## 5. Verification

- [ ] Frequency Drop / 개입 전후 빈도 비교해 감소폭 산출
- [ ] Ninety Day Check / 90일 뒤 재측정해 복귀 여부 확인
- [ ] Substitution Audit / 다른 나쁜 습관으로 옮겨갔는지 점검
