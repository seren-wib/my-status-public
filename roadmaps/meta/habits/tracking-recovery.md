## 1. Tracking Design

- [ ] Binary Metric / 했다·안 했다로만 재는 지표 정의
- [ ] Minimum Standard / 최악의 날에도 되는 하한선 정하기
- [ ] Visible Chain / 눈에 보이는 곳에 연속 기록 남기기
- [ ] Tracking Cost / 기록 자체가 부담이면 축소해 재설계
- [ ] Measure versus Target / 지표가 목표를 대체하는지 점검

## 2. Streak

- [ ] Never Miss Twice / 하루 거르면 다음 날 반드시 복귀하는 규칙 적용
- [ ] Thirty Day Streak / 한 습관 30일 연속 기록
- [ ] Ninety Day Streak / 한 습관 90일 연속 기록
- [ ] Break Log / 끊긴 날의 상황을 빠짐없이 기록

## 3. Recovery Protocol

- [ ] Restart Rule / 중단 후 재개 절차를 문서로 고정
- [ ] Scaled Down Reentry / 복귀할 때 최소 버전으로 진입
- [ ] Failure Post-mortem / 무너진 원인 분석 기록
- [ ] Recovery Time / 중단부터 복귀까지 걸린 일수 기록

## 4. Multiple Habits

- [ ] One at a Time / 동시 착수 습관 수를 제한하고 결과 비교
- [ ] Keystone Claim Check / 핵심 습관 주장의 근거 확인하고 내 데이터로 판정
- [ ] Habit Retirement / 목적을 다한 습관을 내리는 기준
- [ ] Routine Consolidation / 개별 습관들을 하나의 루틴으로 묶기

## 5. Long Term

- [ ] Annual Review / 1년치 기록 놓고 유지·소멸 습관 분류
- [ ] Life Change Adaptation / 환경이 바뀔 때 습관 재설계한 사례 남기기
