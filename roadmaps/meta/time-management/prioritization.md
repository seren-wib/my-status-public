# Prioritization `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-26

## 1. Sorting

- [ ] Urgency versus Importance / 내 목록을 4분면에 배치해 비중 확인
- [ ] Opportunity Cost / 한 건을 고를 때 포기하는 것을 적어 비교
- [ ] Value per Hour / 작업별 산출 대비 소요 시간 계산
- [ ] Pareto Cut / 결과 대부분을 낸 소수 작업 식별하고 나머지 삭제

## 2. Limiting

- [ ] WIP Limit / 동시 진행 항목 수 상한 정하고 초과 시 착수 금지
- [ ] Little's Law / 대기 항목 수와 처리율로 완료까지 걸리는 시간 계산
- [ ] Queue Aging / 오래 묵은 항목의 나이 재서 착수·폐기 판정
- [ ] Single Tasking Trial / 한 번에 하나만 하는 조건으로 하루 돌려 처리량 비교

## 3. Declining

- [ ] Saying No / 거절 문장 준비해 실제 요청 한 건 거절
- [ ] Commitment Audit / 이미 승낙한 것 전부 나열해 유지·해지 판정
- [ ] Sunk Cost Exit / 아까워서 붙잡고 있던 것 하나 중단
- [ ] Scope Cut / 완성 기준을 낮춰 끝낸 사례 만들기

## 4. Constraint

- [ ] Bottleneck Identification / 내 흐름에서 막히는 단계 하나 지목
- [ ] Constraint Relief / 병목에만 자원 몰고 앞뒤 단계 속도 조절
- [ ] Batching / 같은 종류 잡무를 묶어 한 블록에 처리
- [ ] Automation or Delegation / 반복 작업 하나를 자동화하거나 넘기기

## 5. Trade-off Record

- [ ] Decision Log / 우선순위 결정과 근거를 남겨 사후 검토
- [ ] Reversibility Test / 되돌릴 수 있는 결정은 빠르게, 아닌 건 느리게 판정
- [ ] Regret Check / 3개월 뒤 그 결정을 다시 평가해 기록
