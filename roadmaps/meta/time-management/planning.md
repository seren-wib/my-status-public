# Planning `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-26

## 1. Capture

- [ ] Single Inbox / 할 일 유입구를 하나로 합치기
- [ ] Capture Habit / 떠오른 즉시 적는 경로 확보해 1주 유지
- [ ] Inbox Processing Rule / 즉시·위임·보류·삭제로 수집함을 비우는 판정 규칙

## 2. Estimation

- [ ] Estimate Log / 착수 전 예상 시간 적고 실제와 함께 4주 기록
- [ ] Estimation Error Rate / 내 추정 배율 산출해 다음 계획에 곱하기
- [ ] Reference Class Forecasting / 비슷한 과거 작업의 실측치로 새 계획 잡기
- [ ] Task Breakdown / 2시간 넘는 덩어리를 실행 단위로 쪼개기
- [ ] Planning Fallacy / 최선 시나리오로 잡는 경향을 내 기록으로 확인

## 3. Scheduling

- [ ] Timeboxing / 목록의 할 일을 달력의 시간 블록으로 옮기기
- [ ] Maker and Manager Slot / 긴 작업용 시간대와 잡무 시간대 분리
- [ ] Buffer Ratio / 계획에 여유 비율 넣고 초과분 실측
- [ ] Fixed Anchor First / 고정 일정 먼저 박고 나머지를 그 사이에 배치
- [ ] Energy Matching / 시간대별 컨디션에 작업 종류 맞추기

## 4. Review Cycle

- [ ] Weekly Review / 주 1회 수집함·프로젝트·달력 전체 훑기
- [ ] Plan versus Actual / 계획과 실제 차이 큰 3건의 원인 적기
- [ ] Someday List / 지금 안 할 것을 따로 빼 현재 목록 축소
- [ ] Review Streak / 주간 리뷰 8주 연속 채우기

## 5. Horizon

- [ ] Goal to Project / 목표를 결과물이 있는 프로젝트로 환산
- [ ] Next Action / 프로젝트마다 다음 물리적 행동 한 줄 확정
- [ ] Quarter Target / 분기 목표를 3개 이하로 제한하고 종료 시 달성 판정
- [ ] Stalled Project Sweep / 2주 이상 안 움직인 프로젝트 골라 처분 결정
