# PART 1 · Introduction to Balsamiq

## 1. What is Balsamiq?

### Overview of Balsamiq / What is it?

- [ ] Low-fidelity Wireframing Tool / 디테일 버리고 구조만 빠르게 그리는 도구
- [ ] Sketch Skin / 손그림 스타일
- [ ] Structure over Visual Polish / 시각 완성도보다 구조 논의에 집중

### When to Use

- [ ] Early Idea Divergence / 초기 아이디어 발산
- [ ] Stakeholder Alignment Screens / 이해관계자 합의용 화면 구조
- [ ] Hand-off Timing Judgement / High-fidelity 툴로 넘어가는 시점 판단

### Getting Started

- [ ] Product Choice / 클라우드·데스크톱·Confluence·Jira 플러그인 중 선택 `택 1`
- [ ] Project Creation / 프로젝트 생성
- [ ] .bmpr File Structure / 파일 구조
