# PART 2 · The Prospect Theory Framework

## 3. Prospect Theory

- [ ] Reference Dependence / 절대 수준이 아니라 준거점 대비로 평가
- [ ] Loss Aversion / 손실 회피·준거점이 만드는 선택 역전
- [ ] Diminishing Sensitivity / 이득 영역과 손실 영역의 곡률 차이
- [ ] Probability Weighting / 작은 확률 과대평가와 큰 확률 과소평가
- [ ] Framing Effect / 같은 결과를 다르게 진술했을 때 뒤집히는 선호
- [ ] Editing and Isolation / 선택지를 분리해 평가하며 생기는 비일관성
- [ ] Cumulative Extension / 순위 의존 가중으로의 확장과 그 필요

## 4. Reference Points in Action

- [ ] Endowment Effect / 보유가 만드는 지불의사-수취의사 격차
- [ ] Status Quo Bias / 기본값에 머무르려는 힘
- [ ] Mental Accounting / 돈에 꼬리표를 붙여 칸막이를 짓는 회계
- [ ] Sunk Cost Escalation / 매몰비용에 묶인 몰입 상승
- [ ] House Money Effect / 이득을 본 뒤 위험 성향이 달라지는 현상
