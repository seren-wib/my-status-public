- [ ] Network Map / 누가 누구와 이어져 있는가의 지도

- [ ] Offer Audit / 내가 줄 수 있는 것의 목록

- [ ] Forbidden Triad / 강한 연결 둘이 서로 모르기 어려운 이유

- [ ] Degree and Eigenvector Centrality / 연결의 수와 연결의 질을 나눠 보는 지표
- [ ] Network Density / 밀도가 높을수록 정보가 중복되는 구조

- [ ] Small World / 짧은 경로와 높은 군집이 공존하는 구조 (Watts-Strogatz)
- [ ] Preferential Attachment / 연결이 연결을 부르는 누적 이익 (Barabasi)

# PART 3 · Brokerage

## 5. Introduction Craft

- [ ] Double Opt-in / 양쪽 동의를 먼저 받는 소개 절차
- [ ] Mutual Benefit Test / 소개는 양쪽 다 이득이어야 한다는 조건
- [ ] Context Transfer / 소개에 무엇을 얹어 넘겨야 하는가
- [ ] Vouching Risk / 신뢰를 빌려줄 때 지는 책임
- [ ] Credit Distribution / 공을 돌리는 것이 다음 소개를 만드는 구조
- [ ] Referral Loop / 소개가 소개를 부르는 순환

## 6. Brokerage Position

- [ ] Tertius Gaudens / 둘의 분리에서 이익을 얻는 제3자 (Simmel)
- [ ] Tertius Iungens / 둘을 잇는 데서 이익을 얻는 제3자 (Obstfeld)
- [ ] Brokerage Types / 조정·중개·문지기·대표·연락의 유형 분류 (Gould-Fernandez)
- [ ] Bridge Decay / 이어준 두 쪽이 직접 연결되면 사라지는 자리
- [ ] Disintermediation Risk / 중개자가 건너뛰어지는 조건
- [ ] Network Constraint / 내 연결끼리 얽힐수록 줄어드는 자유도
- [ ] Bonding vs Bridging Capital / 결속 자본과 교량 자본의 교환 (Putnam)
- [ ] Closure vs Brokerage / 폐쇄망의 신뢰와 개방망의 기회 사이의 선택 (Coleman-Burt)
- [ ] Information Arbitrage / 두 집단의 정보 시차에서 나오는 이익
- [ ] Vision Advantage / 구조적 공백이 좋은 발상을 만드는 경로 (Burt)
- [ ] Bridge Placement / 어느 두 집단을 잇는 것이 가치가 큰가의 판단
- [ ] Broker Succession / 중개 자리를 넘길 때 관계망이 유지되는 조건
