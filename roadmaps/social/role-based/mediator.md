# PART 3 · Process Design

## 5. Entry and Mandate

- [ ] Invitation vs Imposition / 자발적 중재와 강제 중재의 차이
- [ ] Mediator Mandate / 권한 범위와 결정권 없음의 명시
- [ ] Ground Rules / 절차 규칙의 합의와 집행
- [ ] Confidentiality Regime / 비밀유지의 범위와 예외
- [ ] Impartiality Declaration / 이해관계 공개와 회피 기준
- [ ] Convening Sequence / 누구를 먼저 만나 판을 여는가
- [ ] Interests-Rights-Power / 이익·권리·힘 3접근과 각각의 비용 (Ury-Brett-Goldberg)
- [ ] ADR Spectrum / 협상·조정·중재·소송으로 갈수록 통제권이 이동하는 구조
- [ ] Ripeness Theory / 상호 피해 교착과 출구 인식이 만드는 개입 적기 (Zartman)
- [ ] Mutually Hurting Stalemate / 양측이 모두 아픈 교착의 판정

## 6. Process Architecture

- [ ] Caucus vs Joint Session / 분리 회동과 합동 회의의 용법
- [ ] Agenda Sequencing / 쉬운 쟁점 선행이 만드는 합의 관성
- [ ] Single Text Procedure / 하나의 초안을 함께 고쳐 나가는 절차
- [ ] Issue Bundling / 쟁점을 묶고 쪼개는 것이 결과를 바꾸는 방식
- [ ] Time Structuring / 회기·휴회·마감의 배치
- [ ] Information Symmetrization / 사실 인정의 공통 기반 만들기
- [ ] Forcing Event / 인위적 시한을 세워 결정을 강제하는 설계
- [ ] Dispute System Design / 개별 사건이 아니라 제도로 갈등을 처리하는 설계
- [ ] Procedural Justice / 절차 공정성 인식이 결과 수용을 만드는 기제 (Thibaut-Walker)
- [ ] Shuttle Diplomacy / 당사자를 분리해 왕복 중개하는 구조
- [ ] Multi-track Diplomacy / 공식·비공식 경로의 병행 운용

## 7. Mediation Models and Neutrality

- [ ] Facilitative Mediation / 절차만 관리하고 내용에 개입하지 않는 모델
- [ ] Evaluative Mediation / 중재자가 사안의 강약을 평가해 제시하는 모델
- [ ] Transformative Mediation / 합의보다 역량강화와 상호인정을 목표로 (Bush-Folger)
- [ ] Narrative Mediation / 갈등 서사의 해체와 재구성
- [ ] Neutrality vs Impartiality / 무관심과 공평의 구분, 그리고 관리
- [ ] Biased Mediator Paradox / 편향된 중재자가 더 효과적인 조건
- [ ] Bias Self-audit / 자기 편향의 탐지와 보정 기록
