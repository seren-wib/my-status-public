# PART 2 · People

## 3. Selection and Placement

- [ ] Hiring Signal / 이력이 아니라 신호를 읽는 관점
- [ ] Bench Depth / 대체 가능성을 미리 확보하는 것
- [ ] Peter Principle / 무능해지는 층까지 승진하게 되는 구조
- [ ] Misplacement Cost / 잘못 배치한 사람을 오래 두는 비용
- [ ] Trait to Behavior Shift / 특성론에서 행동론으로 넘어간 연구사
- [ ] Destructive Leadership / 유능하면서 동시에 파괴적인 리더가 가능한 구조
- [ ] Culture through Selection / 문화가 선발·승진·이탈로 각인되는 경로 (ASA 모형)
- [ ] Succession Planning / 후임 후보군을 미리 만드는 설계
- [ ] Leadership Pipeline / 차세대 리더를 조직 안에서 길러내는 구조
- Hiring and Team `위임`

## 4. Development and Feedback

- [ ] Feedback Specificity / 행동 단위로 좁힌 피드백이 작동하는 이유
- [ ] Self-Determination / 자율·유능·관계가 내적 동기를 만든다 (Deci-Ryan)
- [ ] Overjustification Effect / 외적 보상이 내적 동기를 밀어내는 현상
- [ ] Hard Conversation Structure / 성과·태도 문제를 다루는 대화의 구조
- [ ] Transactional Leadership / 교환과 조건부 보상에 기반한 지휘 (Bass)
- [ ] Transformational Leadership / 이상적 영향·영감·지적 자극·개별 배려의 4요소 (Bass)
- [ ] Path-Goal Theory / 목표까지의 경로를 치워 주는 역할로서의 리더 (House)

# PART 3 · Team

## 5. Team Conditions

- [ ] Safety and Standards / 안전감과 높은 기준이 함께 가야 하는 이유
- [ ] Team Norms / 명시된 규범이 암묵 규범을 이기는 조건
- [ ] Social Loafing / 집단이 커질수록 개인 기여가 줄어드는 현상 (Ringelmann)
- [ ] Task Interdependence / 일이 얽힌 정도가 팀 설계를 정한다는 것
- [ ] Meeting as Decision Device / 회의를 전달이 아니라 결정 장치로 보는 관점
- [ ] Leader-Member Exchange / 리더가 만드는 내집단과 외집단의 격차
- Team `위임`

## 6. Authority and Delegation

- [ ] Span of Control / 한 사람이 직접 관리할 수 있는 인원의 한계
- [ ] Delegation Levels / 보고·상의·통보·전권으로 나뉘는 위임 단계
- [ ] Accountability without Authority / 책임만 주고 권한을 안 주는 실패 구조
- [ ] Micromanagement Trap / 통제가 역량 성장을 막는 경로
- [ ] Leader Bottleneck / 지도자 본인이 병목이 되는 지점
- [ ] Reversible Delegation / 위임을 회수할 때 치르는 신뢰 비용
- [ ] Situational Leadership / 성숙도에 따라 지시와 위임을 바꾸는 모형 (Hersey-Blanchard)
- [ ] Contingency Model / 상황 호의성과 리더 성향의 적합 (Fiedler)
- [ ] Servant Leadership / 권위를 봉사에서 끌어오는 계열 (Greenleaf)

# PART 4 · Scale

## 7. Scaling Structure

- [ ] Dunbar Number / 관계 유지 한계가 조직 계층을 만드는 이유
- [ ] Layer Distortion / 계층이 늘 때 정보가 왜곡되는 비율
- [ ] Conway's Law / 조직의 소통 구조가 산출물 구조를 결정한다
- [ ] Inverse Conway Maneuver / 원하는 산출 구조에 맞춰 조직을 먼저 바꾸는 설계
- [ ] Coordination Overhead / 인원이 늘 때 소통 경로가 제곱으로 느는 문제 (Brooks)
- [ ] Autonomy-Alignment Tradeoff / 자율과 정렬 사이의 교환 곡선
- [ ] Founder Transition / 창업자에서 전문 경영으로 넘어가는 국면

## 8. Leading Through Others

- [ ] Leader of Leaders / 실무자가 아니라 리더를 통해 움직이는 전환
- [ ] Skip-level Signal / 한 단계 건너 듣는 정보의 가치와 위험
- [ ] Cascade Distortion / 메시지가 층을 내려가며 변형되는 현상
- [ ] Management Mirror / 중간 리더가 상급자의 행동을 복제하는 구조
- [ ] Tolerated Minimum / 지도자가 용인한 최저 수준이 곧 기준이 된다는 것
- [ ] Attention as Signal / 무엇을 묻는지가 조직의 우선순위를 만드는 기제
- [ ] Three Levels of Culture / 인공물·표방 가치·기저 가정의 층 (Schein)
- [ ] Espoused vs Enacted Values / 내건 가치와 실제로 보상되는 행동의 괴리
- [ ] Ritual and Artifact / 반복 의례가 규범을 제도로 굳히는 방식
- [ ] Post-departure Persistence / 지도자 부재 후에도 규범이 남는 조건

# PART 5 · Crisis and Change

## 9. Crisis Command

- [ ] Crisis Tempo / 평시와 다른 결정 주기로의 전환
- [ ] Incident Command Structure / 위기에 지휘 계통을 단일화하는 설계
- [ ] Information Triage / 불확실한 정보의 등급 구분
- [ ] Crisis Communication / 사실·조치·다음 시점을 나눠 말하는 원칙
- [ ] Bad News Velocity / 나쁜 소식이 빨리 올라오게 만드는 조건
- [ ] Normalization of Deviance / 작은 일탈이 표준으로 굳는 누적 (Vaughan)

## 10. Change Management

- [ ] Technical vs Adaptive Challenge / 해법이 있는 문제와 사람이 변해야 하는 문제 (Heifetz)
- [ ] Productive Disequilibrium / 견딜 만한 불편 수준을 유지하는 조절
- [ ] Giving Work Back / 문제를 당사자에게 되돌리는 개입
- [ ] Resistance as Information / 저항을 손실 예고로 읽는 관점
- [ ] Loss Accounting / 변화가 누구에게서 무엇을 빼앗는지의 계산
- [ ] Change Fatigue / 연속된 변화가 수용력을 소진시키는 현상
