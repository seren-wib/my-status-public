# PART 2 · The Interview

## 3. Rapport and Working Alliance

- [ ] Scharff Technique / 이미 다 알고 있다는 착각을 유도해 확인·정정을 끌어내는 비강압 기법
- [ ] Illusion of Knowing It All / 샤르프 기법의 핵심 전제와 그 실험적 검증
- [ ] Rapport as Yield / 라포가 정보 산출량을 늘린다는 현장 실증 (Alison, HIG)
- [ ] Autonomy Preservation / 선택권을 남겨두는 것이 진술을 여는 조건인 이유
- [ ] Motivational Interviewing Adaptation / 저항을 밀지 않고 양가감정을 다루는 면담 태도
- [ ] Interpersonal Behaviour Circle / 면담자와 피면담자의 상호작용을 원환 모형으로 본 틀
- [ ] PEACE Model / 준비·관여·설명·종결·평가로 구성된 비고발형 면담 체계
- [ ] Accusatorial vs Information-gathering / 두 계열의 정보 산출량과 오류율 비교 연구
- [ ] HIG Research Program / 고가치 억류자 심문 그룹이 축적한 실증 연구
- Bonding `위임`

## 4. Question Architecture

- [ ] Funnel Structure / 개방형에서 폐쇄형으로 수렴하는 깔때기 구조
- [ ] Leading Question Contamination / 유도 질문이 답이 아니라 기억 자체를 오염시키는 기제
- [ ] Presupposition in Wording / 어휘에 심긴 전제가 응답을 바꾸는 효과 (Loftus)
- [ ] Question Sequencing / 질문 순서가 만드는 정보 손실과 그 회복

- [ ] Memory as Reconstruction / 기억은 재생이 아니라 재구성이라는 전제
- [ ] Misinformation Effect / 사후 정보가 원기억을 덮어쓰는 현상 (Loftus)

## 9. Strategic Use of Evidence

- [ ] Evidence Strength Framing / 증거의 강도를 어떻게 제시하느냐가 만드는 효과 차이

# PART 5 · Hostile Interviews

## 11. Resistance Management

- [ ] Counter-interrogation Training / 훈련된 피면담자가 따르는 대응 교범의 구조
- [ ] No-comment Interview / 묵비 대응 상황에서의 면담 운용
- [ ] Adaptive Interviewing / 저항 유형에 따라 접근을 전환하는 ORBIT 계열 모형
- [ ] Duration and Fatigue Effects / 장시간 면담이 진술 신뢰도에 미치는 영향
- [ ] Coercion Threshold / 압박이 진술의 증거 가치를 파괴하는 경계
- [ ] Rights and Admissibility / 고지·기록 요건이 진술의 효력을 결정하는 구조
- [ ] Reid Technique / 고발적 9단계 심문 구조와 그 전제
- [ ] Minimization and Maximization / 축소·과장 화법이 만드는 암묵적 형량 약속 (Kassin)

## 12. Vulnerable Interviewees

- [ ] Suggestibility Scale / 피암시성의 개인차를 측정하는 척도 (Gudjonsson)
- [ ] Compliance vs Suggestibility / 순응과 피암시성의 구분과 각각의 위험
- [ ] Minor Interview Protocol / 미성년 면담의 발달 단계별 제약
- [ ] Intellectual Disability Safeguards / 지적장애 피면담자 보호 절차
- [ ] Appropriate Adult / 제3자 입회 제도의 기능과 그 한계
- [ ] Interpreter-mediated Interview / 통역 개입이 만드는 정보 손실과 왜곡

## 13. False Confession

- [ ] Voluntary False Confession / 외부 압력 없이 발생하는 허위자백 유형
- [ ] Compliant False Confession / 상황 압력에 순응해 나오는 허위자백 (Kassin)
- [ ] Internalized False Confession / 스스로 죄를 믿게 되는 내재화형 허위자백
- [ ] Corroboration Inflation / 자백 이후 다른 증거가 자백에 맞춰 변형되는 현상
- [ ] Exoneration Case Base / 무죄 확정 사례가 드러낸 면담 실패의 통계
