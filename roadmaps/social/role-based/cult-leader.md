# PART 3 · Doctrine

## 5. Doctrine Architecture

- [ ] Cosmology Construction / 기원·의미·종말을 한 체계로 봉합하기
- [ ] Loaded Language / 사고를 멈추는 상투구와 내부 전용 어휘 (Lifton)
- [ ] Sacred Science / 교리를 검증 불가한 절대 진리로 세우기
- [ ] Knowledge Tiering / 단계별로만 공개되는 비의의 구조
- [ ] Doctrine over Person / 개인 경험보다 교리가 우선한다는 규칙
- [ ] Prophecy Design / 검증 가능한 예언과 불가능한 예언의 배분
- [ ] Mystical Manipulation / 예정된 우연을 연출해 필연으로 읽히게 하기
- [ ] Millenarian Narrative / 종말·구원 서사가 헌신을 최대화하는 구조
- [ ] Revolutionary Suicide Framing / 집단 자살을 저항 행위로 재정의한 논리

## 6. Sealing the Worldview

- [ ] Unfalsifiability / 반증 가능성을 제거하는 서술 방식
- [ ] Outside Information Framing / 외부 정보를 사전에 오염으로 규정
- [ ] Persecution Narrative / 비판을 예언 성취로 흡수하는 구조
- [ ] Thought-terminating Cliché / 의심이 시작되는 지점에서 끊는 정형구
- [ ] Doubt as Personal Flaw / 의심을 개인의 결함으로 귀속시키기
- [ ] Failed Prophecy Reframing / 예언 실패 후 신념이 오히려 강해지는 기제 (Festinger)
- [ ] Dispensing of Existence / 존재 자격의 배분까지 가는 마지막 기준
- [ ] Siege Mentality / 포위 인식이 폭력을 자기방어로 번역하는 구조
- [ ] Fragile Apocalyptic Dynamic / 외부 압력과 내부 종말론의 상호작용
