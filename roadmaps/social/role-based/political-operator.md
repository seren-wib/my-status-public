# PART 1 · Reading the Board

## 1. Power Topography

- [ ] Decision Rights Map / 누가 무엇을 최종 승인하는가의 지도
- [ ] Veto Player / 혼자서 부결시킬 수 있는 자리 (Tsebelis)
- [ ] Patron-Client Chain / 후원과 수혜로 이어진 수직 사슬
- [ ] One-dimensional Power / 공개된 쟁점에서 누가 이기는가로 권력을 재는 관점 (Dahl)
- [ ] Second Face of Power / 무엇을 쟁점으로 만들지 않는가에 있는 권력 (Bachrach-Baratz)
- [ ] Third Dimension / 선호 자체를 형성하는 권력 (Lukes)
- [ ] False Consciousness Problem / 3차원 권력 주장이 검증되기 어려운 이유
- [ ] Power Resources / 자원·지위·정보가 권력으로 전환되는 조건
- [ ] Legitimacy Types / 전통·카리스마·법합리 지배의 구분 (Weber)

# PART 2 · Votes and Coalitions

## 3. Vote Counting

- [ ] Whip Count / 찬반과 미정의 사전 집계
- [ ] Soft vs Hard Commitment / 확답과 여지 있는 답의 구별
- [ ] Pivotal Voter / 결과를 뒤집는 위치의 표
- [ ] Abstention Value / 반대 대신 기권을 받아내는 계산
- [ ] Quorum Arithmetic / 정족수가 표 계산을 바꾸는 방식
- [ ] Proxy and Delegation / 위임장·대리 표결의 취급
- [ ] Outcome Forecasting / 표결·인사 결과의 사전 예측과 사후 대조
- [ ] Median Voter Theorem / 단일 축에서 중위 투표자가 결과를 정하는 조건 (Black-Downs)
- [ ] Arrow Impossibility / 다수결이 일관된 집합 선호를 만들지 못한다는 정리
- [ ] Cycling and Instability / 다차원 쟁점에서 안정 균형이 사라지는 문제

## 4. Coalition Building

- [ ] Minimum Winning Coalition / 이길 만큼만 모으는 이유 (Riker)
- [ ] Size Principle / 연합이 커질수록 몫이 줄어드는 구조
- [ ] Side Payment / 본안 밖에서 지불하는 대가
- [ ] Pork Barrel / 지역·부문 배분으로 지지를 사는 구조
- [ ] Coalition Fragility / 사안이 바뀌면 무너지는 연합의 조건
- [ ] Two-Level Games / 대외 협상이 내부 비준 제약에 묶이는 구조 (Putnam)
- [ ] Win-set Size / 국내 재량이 좁을수록 협상력이 커지는 역설
- [ ] Tied Hands Strategy / 스스로 묶여 있음을 보여 양보를 얻는 수 (Schelling)
- [ ] Long Coalition Maintenance / 여러 사안에 걸친 연합을 유지하는 회계

# PART 5 · Making the Rules

## 9. Rulemaking

- [ ] Statutory Language / 문안 한 단어가 만드는 재량의 폭
- [ ] Sunset Clause / 시한을 붙여 재협상을 예약하는 조항
- [ ] Grandfathering / 기존 이해관계를 면제해 반대를 줄이는 장치
- [ ] Delegation to Agency / 결정을 행정부로 넘기는 설계
- [ ] Ambiguity by Design / 합의를 위해 일부러 남기는 모호성

## 10. Implementation and Bureaucracy

- [ ] Bureaucratic Politics Model / 정책은 조직 이익의 절충 산물이라는 관점 (Allison)
- [ ] Standard Operating Procedure / 조직의 관성이 결정을 왜곡하는 경로
- [ ] Street-level Discretion / 집행 말단의 재량이 규칙을 다시 쓰는 현상 (Lipsky)
- [ ] Regulatory Capture / 규제 기관이 피규제자에게 포획되는 구조 (Stigler)
- [ ] Revolving Door / 인적 이동이 만드는 이해 정렬
