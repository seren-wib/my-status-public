## 1. How Persuasion Works

- [ ] Two Routes / ELM — central route vs peripheral route

## 2. Cialdini's Levers

- [ ] Cialdini's Principles / reciprocity, scarcity, social proof, authority, liking, commitment
- [ ] Reciprocity and Concession / 받으면 갚고, 양보엔 양보로 (rejection-then-retreat)
- [ ] Commitment and Consistency / 작은 약속이 큰 행동을 부른다
- [ ] Unity / 같은 편이라는 정체성 (7번째 원칙)

## 3. Attitude Change

- [ ] Attitude vs Behavior / 태도와 행동 사이의 간극
- [ ] Cognitive Dissonance / 행동이 거꾸로 태도를 바꾼다
- [ ] Self-Perception / 자기 행동을 관찰해 태도를 추론
- [ ] Inoculation / 약한 반론을 미리 접종해 태도 방어

## 4. Reactance and Limits

- [ ] Psychological Reactance / 강요는 역효과를 부른다
- [ ] Sleeper Effect / 출처는 잊혀도 메시지는 남는다
- [ ] Boomerang / 설득이 오히려 반대를 굳히는 경우
