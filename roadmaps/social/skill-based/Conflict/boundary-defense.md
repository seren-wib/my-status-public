## 1. What a Boundary Is

- [ ] Boundary vs Request / 경계는 부탁이 아니라 내 행동 규칙
- [ ] Boundary vs Control / 상대를 통제하는 것이 아니다
- [ ] Values Behind the Line / 무엇을 지키려는 선인지 먼저 정하기

## 2. Stating the Line

- [ ] Plain Statement / 짧고 분명하게, 수식 없이
- [ ] Consequence Notice / 어길 경우 내가 할 행동을 미리 알리기
- [ ] No Over-explanation / 이유를 길게 대면 협상거리가 된다
- [ ] Timing of Notice / 침범 직후에 알려야 선이 선다

## 3. The Art of Refusal

- [ ] Refusal without Apology / 사과를 붙이지 않고 거절하기
- [ ] Broken Record / 같은 답을 반복해 버티기
- [ ] Partial Yes / 범위·조건을 줄여 받는 수락
- [ ] Saying No Upward / 힘이 위인 상대에게 거절하기
- [ ] Refusing without Rejecting / 사안 거절과 사람 거절의 분리

## 4. Repeated Violation

- [ ] Testing vs Real Violation / 떠보기와 진짜 침범 구분

- [ ] Following Through / 예고한 결과를 반드시 실행
- [ ] Third-party Escalation / 상급자·제도로 올리는 시점
