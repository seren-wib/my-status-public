## 2. Sequencing

- [ ] Trust Before Leverage / 지렛대는 신뢰 위에서만 걸린다
- [ ] Foot in the Door / 작은 승낙에서 시작

## 3. Combining Levers

- [ ] Lever Stacking / 정보·부하·관계를 겹쳐 쓰기
- [ ] Load Plus Deadline / 지친 시점에 마감 걸기

## 4. Sustaining Control

- [ ] Consent Illusion / 스스로 택했다고 믿게 유지

- [ ] Norm Drift / 기준을 조금씩 옮겨 굳히기
- [ ] Maintenance Cost / 유지에 드는 비용과 피로

## 5. Staying Undetected

- [ ] Plausible Deniability / 부인 가능성 확보

- [ ] Cross-check Blocking / 교차 검증 경로 차단
- [ ] Exposure Triage / 들켰을 때의 수습 순서

## 6. Failure Modes

- [ ] Reactance Trigger / 압박이 역효과로 뒤집히는 지점
- [ ] Over-extraction / 너무 많이 뽑아 관계가 끊김
- [ ] Third-party Break / 제3자 개입으로 무너짐
