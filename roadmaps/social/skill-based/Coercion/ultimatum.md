# Ultimatum `AI 생성`

## 1. Structure of an Ultimatum

- [ ] Demand, Deadline, Consequence / 세 요소가 다 있어야 성립
- [ ] Compliance Criteria / 무엇을 보면 따랐다고 할지 미리 정하기
- [ ] Single Issue Rule / 여러 요구를 한 통첩에 묶을 때의 실패
- [ ] Deadline Realism / 상대가 실제로 맞출 수 있는 기한인가

## 2. Commitment

- [ ] Commitment Device / 물러설 수 없게 스스로 묶기 (Schelling)
- [ ] Burning Bridges / 퇴로를 없애 신뢰성을 사는 것
- [ ] Tying Hands vs Sinking Cost / 자기구속 두 방식의 차이
- [ ] Delegation to a Rule / 재량을 없애 나도 어쩔 수 없게 만들기
- [ ] Commitment Trap / 스스로 묶여 손해 나는 실행에 끌려가기

## 3. Graduated Pressure

- [ ] Salami Tactics / 통첩 없이 조금씩 잘라내는 압박
- [ ] Escalation Ladder / 칸마다 되돌릴 여지를 남기기
- [ ] Ultimatum as Last Rung / 통첩은 사다리의 마지막 칸
- [ ] Reciprocal Escalation / 맞대응으로 통제를 잃는 지점

## 4. Exits

- [ ] Face-saving Exit / 굴복으로 보이지 않는 출구 설계
- [ ] Ambiguous Compliance / 형식적 체면과 실질적 양보의 분리
- [ ] Private Delivery / 청중이 없어야 물러설 수 있다
- [ ] Walk-away Point / 내가 접을 지점을 미리 정해두기

## 5. After Refusal

- [ ] Execute or Fold / 거부당한 뒤에는 둘 중 하나뿐
- [ ] Credibility Repair / 실행하지 못했을 때의 수습
- [ ] Diagnosis of Failure / 지렛대 부족인지 신뢰성 부족인지
- [ ] Relationship Salvage / 통첩 이후 관계를 되돌리는 경로
