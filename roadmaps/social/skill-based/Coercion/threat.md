# Threat Construction `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. Coercion and Deterrence

- [ ] Compellence vs Deterrence / 하게 만들기와 못 하게 막기의 구분 (Schelling)
- [ ] Burden of Action / 먼저 움직여야 하는 쪽이 누구인가
- [ ] Status Quo Advantage / 억지가 강압보다 쉬운 이유
- [ ] Threat vs Warning / 내가 부과하는 비용인가 그냥 예고인가

## 2. Anatomy of a Threat

- [ ] Demand Specification / 무엇을 하면 위협이 철회되는지
- [ ] Cost Sizing / 상대 기준의 비용, 내 기준이 아니라
- [ ] Assurance Clause / 따르면 건드리지 않는다는 보장
- [ ] Proportionality / 요구와 비용의 균형이 깨지는 지점

## 3. Credibility

- [ ] Capability and Will / 할 수 있는가와 할 것인가는 별개
- [ ] Cost to the Threatener / 실행이 나에게도 비싸면 안 믿는다
- [ ] Reputation Stock / 과거 실행 이력이 현재의 담보
- [ ] Audience Cost / 공개 선언이 물러설 자유를 없애는 효과
- [ ] Third-party Enforcement / 실행 주체를 내가 아닌 곳에 두기

## 4. Clarity and Ambiguity

- [ ] Explicit Threat / 요구·기한·결과를 못 박을 때의 이득
- [ ] Calculated Ambiguity / 모호함이 오히려 힘을 키우는 조건
- [ ] Leaving Something to Chance / 통제하지 못하는 위험을 남기기 (Schelling)
- [ ] Public vs Private Channel / 구속력과 체면 보존의 맞교환
- [ ] Unstated Pressure / 명시하지 않고 전달되는 압박과 부인 가능성

## 5. Cost of Failure

- [ ] Bluff Detection / 빈 위협이 읽히는 신호
- [ ] Credibility Depletion / 한 번 안 지키면 다음이 안 먹힌다
- [ ] Backlash and Coalition / 위협이 저항과 연합을 부르는 지점
- [ ] Relationship Damage / 위협 자체가 관계에 남기는 비용
