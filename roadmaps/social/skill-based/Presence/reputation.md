# Reputation `AI 생성`

## 1. How Reputation Forms

- [ ] Reputation as Shared Belief / 내 이미지가 아니라 남들끼리 공유하는 평가
- [ ] Indirect Reciprocity / 평판이 협력을 지탱하는 기제
- [ ] Repeated Interaction / 반복이 예상돼야 평판이 값을 가진다
- [ ] Domain Specificity / 평판은 분야마다 따로 쌓인다

## 2. Transmission

- [ ] Gossip as Channel / 뒷말이 주 전달로
- [ ] Network Position / 누구를 거치느냐가 전파 범위를 정한다
- [ ] Distortion in Relay / 전달될수록 단순화·과장
- [ ] Reference Checking / 사람들이 실제로 확인하는 경로

## 3. Asymmetry

- [ ] Slow Build, Fast Loss / 쌓기는 오래, 잃기는 한 번
- [ ] Negativity Bias / 나쁜 정보의 과대 가중
- [ ] Single Violation / 정직성 위반은 한 건으로 결론난다
- [ ] Ability vs Integrity Trust / 두 신뢰는 무너지는 방식이 다르다

## 4. Building

- [ ] Consistency over Intensity / 강한 한 번보다 어긋나지 않는 반복
- [ ] Promise Sizing / 지킬 수 있는 크기로 약속하기
- [ ] Visible Reliability / 보이지 않는 성실은 평판이 안 된다
- [ ] Testimonial / 사회적 증언 확보

## 5. Damage and Recovery

- [ ] Fast Acknowledgment / 초기 대응 속도
- [ ] Substance over Statement / 말이 아니라 조치로 갚기
- [ ] Recovery Difference / 능력 실수는 회복되고 부정직은 잘 안 된다
- [ ] Rebuilding Timeline / 새 증거의 누적으로만 돌아온다
