## 1. Vision and Purpose

- [ ] Vision Articulation / 왜 이걸 하는지 그림으로 전달
- [ ] Purpose over Task / 과제가 아니라 의미로 동기 연결
- [ ] Concrete Picture / 추상 구호 아닌 구체적 지향점
- [ ] Repetition / 방향은 반복해야 스며듦

## 2. Goals and Priorities

- [ ] Goal Setting / 도달점을 관찰 가능하게 정의
- [ ] Prioritization / 다 못 하니 순서를 정함
- [ ] Trade-off / 무엇을 포기할지 명시
- [ ] Focus / 소수에 집중, 나머지는 버림

## 3. Decision-Making

- [ ] Decision Ownership / 결정하고 그 책임을 짐
- [ ] Reversible vs Irreversible / 되돌릴 수 있는 결정과 아닌 것 구분
- [ ] Speed vs Deliberation / 결정 속도와 숙고의 균형
- [ ] Involving Others / 누구를 결정에 넣을지 판단
- [ ] Communicating the Why / 결정 배경 설명으로 납득 확보

## 4. Judgment Under Uncertainty

- [ ] Deciding Without Full Data / 정보 부족 상태의 판단
- [ ] Bet Framing / 결정을 확률적 베팅으로 봄
- [ ] Changing Course / 틀렸을 때 방향 수정할 용기
- [ ] Living with Regret / 최선의 선택도 나쁜 결과를 낼 수 있음

## 5. Accountability

- [ ] Owning Outcomes / 결과 책임 회피 안 함
- [ ] Shielding the Team / 실패는 내가, 공은 팀에게
- [ ] Post-decision Review / 결정 복기로 판단력 보정
