# Cover Story `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. Statement Design

- [ ] Scope Minimalism / 필요한 만큼만 주장하고 나머지는 건드리지 않기
- [ ] Detail Density Tradeoff / 세부가 많을수록 신빙성은 오르고 반증 표면도 넓어짐
- [ ] Verifiability Balance / 확인 가능한 세부와 확인 불가능한 세부의 배합
- [ ] Truth Embedding / 실제 겪은 일을 뼈대로 삼기
- [ ] Unfalsifiable Claims `선택` / 검증 경로가 없는 영역으로 주장을 옮기기

## 2. Preparation and Rehearsal

- [ ] Question Anticipation / 나올 질문을 먼저 목록으로 뽑기
- [ ] Rehearsal to Fluency / 반복으로 매끄러움을 만드는 것의 이점과 대가
- [ ] Unanticipated Angles / 준비하지 못한 방향에서 먼저 무너짐
- [ ] Fallback Branches / 반박당했을 때 물러설 지점을 미리 정하기

## 3. Memory Load

- [ ] Fabrication Memory Cost / 지어낸 것은 겪은 것보다 유지 비용이 크다
- [ ] Anchoring to Real Events / 실제 사건에 붙여 회상 부담 줄이기
- [ ] Source Monitoring Failure / 누구에게 무엇을 말했는지 혼동
- [ ] Written Aid Risk / 메모로 관리하면 그 메모가 증거가 됨

## 4. Consistency Maintenance

- [ ] Single Canonical Version / 판본을 하나로 고정하고 파생을 만들지 않기
- [ ] Consistency over Retellings / 반복 진술 사이의 어긋남
- [ ] Overconsistency Signal / 토씨까지 같은 진술은 암기의 표시
- [ ] Timeline Integrity / 시간·순서·동시성의 정합
- [ ] Detail Drift / 되풀이할수록 세부가 늘어나는 경향

## 5. Collapse Points

- [ ] Statement-Evidence Mismatch / 상대가 이미 확보한 사실과의 충돌
- [ ] Third-party Contradiction / 다른 사람의 진술과 어긋나는 지점
- [ ] Exposure Cost / 하나가 무너지면 진술 전체의 신뢰가 사라짐
- [ ] Correction Timing / 고수를 접고 정정할 시점 판단
