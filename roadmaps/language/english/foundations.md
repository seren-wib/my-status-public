# PART 3 · Flow and Frame (Rhythm · Word Order)

## 7. Sentence Stress and Rhythm

- [ ] Content Word Stress / 문장 10개에서 내용어에 밑줄 긋고 그 부분만 세게 읽기
- [ ] Function Word Reduction / and·of·to를 약형으로 흘려 문장 10개 읽어 녹음
- [ ] Shadowing Minute / 짧은 원어민 음성 1분 그림자처럼 따라 말하기 3회 `추천`
- [ ] Rhythm Compare / 같은 문장의 내 녹음과 원음을 나란히 듣고 차이 한 줄 적기

## 8. Linking

- [ ] Consonant Vowel Link / turn it off처럼 자음+모음 연음 문장 10개 읽기
- [ ] T Flap / water·better의 굴리는 t로 단어 10개 녹음
- [ ] Reduction Phrases / gonna·wanna 같은 축약 표현 5개를 문장 안에서 말해보기
- [ ] Linked Sentence Test / 연음 들어간 문장 5개를 끊김 없이 자연 속도로 녹음

## 9. SVO Skeleton

- [ ] SVO Sentences / 주어+동사+목적어 뼈대로 내 하루 문장 10개 쓰기
- [ ] Be Sentences / be동사 문장 10개 쓰고 소리내어 읽기
- [ ] Yes No Questions / 위에서 쓴 문장들을 의문문으로 바꿔 10개 말하기
- [ ] Wh Questions / who·what·where·when·why·how로 질문 6개 만들기
- [ ] Negation Flip / 긍정문 10개를 부정문으로 바꿔 말하기
- [ ] Word Order Scramble / 단어를 뒤섞어 놓고 어순 맞춰 문장 10개 조립
- [ ] One Minute Self Intro / 배운 골격만으로 1분 자기소개 말해 녹음
