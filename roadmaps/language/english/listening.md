# Listening `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-26

# PART 1 · Opening the Ear (A1~A2)

## 1. Slow Audio

- [ ] Slow Podcast Episode / 학습자용 느린 음성 한 에피소드 끝까지 듣기
- [ ] Triple Listen / 같은 에피소드 3회 반복해 새로 들린 부분 표시하기
- [ ] Script Compare / 듣고 나서 스크립트 대조해 놓친 구간 확인하기
- [ ] Picture Match Listen / 음성 설명 듣고 맞는 그림 고르기 10문제 풀기
- [ ] Daily Ten Minutes / 하루 10분 듣기 2주 연속 유지하기 `추천`

## 2. Numbers and Spelling

- [ ] Number Dictation / 가격·전화번호·연도 듣고 받아적기 20개
- [ ] Date and Time Catch / 날짜·시간 표현 듣고 받아적기 20개
- [ ] Spelling Dictation / 철자 불러주는 이름·단어 10개 받아적기
- [ ] Minimal Pair Quiz / 비슷한 발음 단어쌍 듣고 구분 20문제 풀기 (예: ship/sheep)

## 3. Short Dialogues

- [ ] Dialogue Q&A / 짧은 대화 듣고 질문에 답하기 10세트
- [ ] Scene Guessing / 대화만 듣고 장소·화자 관계 추측 후 확인하기
- [ ] Instruction Follow / 간단한 영어 지시 음성 듣고 그대로 수행하기 5회
- [ ] Line-by-Line Shadow / 한 줄씩 멈춰 따라 말하며 대화 하나 끝내기 `선택`

# PART 2 · Entering Real Speed (B1)

## 4. Podcasts

- [ ] Learner Podcast Run / 학습자용 팟캐스트 5화 연속 듣기
- [ ] First Native Episode / 일반인 대상 팟캐스트 한 화 완청하고 주제 말하기
- [ ] Gist Summary / 한 에피소드 듣고 한국어 3문장으로 요약하기
- [ ] Podcast Habit / 팟캐스트 주 3회 한 달 유지하기

## 5. Shows with English Subtitles

- [ ] English-Subtitle Episode / 드라마 한 에피소드 영어 자막으로 보기
- [ ] Expression Harvest / 회당 표현 3개씩 채집해 노트 30개 채우기
- [ ] Rewind Discipline / 안 들린 대사 되감아 자막으로 확인하는 방식으로 한 편 보기

### First Series `택 1`

- [ ] Sitcom Season / 20분대 시트콤 한 시즌 영어 자막 완주하기
- [ ] Animation Season / 애니메이션 한 시즌 영어 자막 완주하기
- [ ] Drama Season / 40분대 드라마 한 시즌 영어 자막 완주하기

## 6. Song Lyrics

- [ ] Lyric Dictation / 좋아하는 노래 한 곡 가사 안 보고 받아적은 뒤 대조하기
- [ ] Linking Sound Marking / 가사에서 연음으로 뭉개지는 구간 5곳 찾아 표시하기
- [ ] Ten Song Decode / 영어 노래 10곡 가사 뜻 파악하고 들으며 따라가기
- [ ] Live Version Compare / 같은 곡 라이브 버전 듣고 스튜디오와 달라진 부분 알아채기 `선택`

# PART 3 · Dropping the Subtitles (B2)

## 7. Subtitle Weaning

- [ ] No-Subtitle Rewatch / 본 적 있는 에피소드 하나 자막 없이 다시 보고 줄거리 말하기
- [ ] First-Watch Blind / 처음 보는 에피소드 무자막 시청 후 영어 자막으로 검증하기
- [ ] Blind Season Run / 무자막으로 한 시즌 완주하기
- [ ] Comprehension Score / 무자막 시청 이해도를 회차마다 퍼센트로 기록해 추이 보기

## 8. News Listening

- [ ] News Bulletin / 영어 뉴스 브리핑 하나 듣고 헤드라인 3개 재구성하기
- [ ] Info Segment Numbers / 날씨·경제 코너 듣고 핵심 수치 받아적기
- [ ] Headline vs Detail / 같은 뉴스의 요약본과 상세 보도 듣고 추가된 정보 적기
- [ ] Two-Week News Ear / 뉴스 듣기 하루 1건 2주 연속하기

## 9. Dictation Routine

- [ ] Sentence Dictation Fifty / 문장 단위 받아쓰기 50문장 누적하기
- [ ] One-Minute Dictation / 1분 분량 통으로 받아쓰고 원문 대조하기
- [ ] Error Pattern Log / 틀린 원인을 연음·축약·어휘로 분류해 기록하기
- [ ] Weekly Dictation Month / 받아쓰기 주 3회 한 달 유지하기 `추천`

# PART 4 · The Long Haul (C1)

## 10. Talks and Interviews

- [ ] Full Talk / 15분 이상 강연 완청 후 핵심 주장 3개 요약하기
- [ ] Interview Reconstruction / 인터뷰 하나 완청하고 질문 목록 재구성하기
- [ ] Note and Rebuild / 들으며 키워드만 적고 노트만 보고 내용 복원해 말하기
- [ ] Lecture Series / 강의 시리즈 3강 이상 연속 완청하기
- [ ] Q&A Session Follow / 강연 뒤 청중 질의응답까지 듣고 질문 요지 받아적기

## 11. Speed Training

- [ ] 1.25x Episode / 팟캐스트 한 화 1.25배속으로 완청하기
- [ ] 1.5x Familiar Topic / 아는 주제 콘텐츠 1.5배속으로 완청하기
- [ ] Default Speed Up / 평소 듣는 팟캐스트 기본 배속을 올려 2주 유지하기
- [ ] Speed Down Check / 배속 뒤 원속으로 돌아와 이해 여유 확인하기

## 12. Meetings and Debates

- [ ] Panel Position Map / 다인 패널 토론 듣고 화자별 입장 정리하기
- [ ] Debate Verdict / 토론 완청 후 어느 쪽이 설득력 있었는지 근거 들어 판정하기
- [ ] Long Meeting Recap / 1시간짜리 회의·공청회 영상 듣고 결정 사항 요약하기

# PART 5 · A Native Ear (C2)

## 13. Accents and Dialects

- [ ] Accent Lineup / 미국·영국·호주 화자 듣고 출신 구분 10문제 자가 테스트하기
- [ ] Heavy Accent Interview / 강한 지역 억양 인터뷰 하나 완청하기 (예: 스코틀랜드·아일랜드)
- [ ] Accent Sound Notes / 같은 문장을 억양별로 듣고 달라지는 모음·자음 적기
- [ ] Non-native Accent / 비원어민 억양 화자의 발표 듣고 요약하기

## 14. Fast and Dense Speech

- [ ] Rap Verse Dictation / 랩 한 벌스 받아적고 가사 대조하기
- [ ] Stand-up Special / 스탠드업 코미디 무자막 시청 후 웃음 포인트 3개 설명하기
- [ ] Rapid Banter / 토크쇼의 빠른 주고받기 무자막으로 따라가며 농담 짚기

## 15. Degraded Audio

- [ ] Street Interview / 소음 배경의 야외 인터뷰 듣고 요지 받아적기
- [ ] Phone Quality Call / 전화 음질 인터뷰·라디오 콜 듣고 내용 요약하기
- [ ] Announcement Catch / 공항·기내 방송풍 안내 음성 듣고 정보 받아적기
- [ ] Overlapping Talk / 말이 겹치는 대화 구간 듣고 화자별 발언 분리하기
