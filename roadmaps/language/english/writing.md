# PART 1 · Warming Up the Hand (A1~A2)

## 1. Copying Sentences

- [ ] First Copy Set / 쉬운 문장 열 개 그대로 베껴쓰기
- [ ] Daily Copy Week / 하루 다섯 문장 베껴쓰기 1주 연속
- [ ] Full Page Copy / 짧은 지문 하나를 한 페이지 통째로 베껴쓰기
- [ ] Pattern Swap / 베낀 문장의 단어 하나씩 바꿔 새 문장 만들기
- [ ] Dictation Check / 들은 문장 받아 적고 원문과 대조해 틀린 곳 표시

## 2. My Own Sentences

- [ ] Fill-in Sentences / 이름·나이·사는 곳 빈칸 문장을 내 정보로 완성
- [ ] Three Sentence Intro / 세 문장 자기소개 쓰기
- [ ] Daily One-Liner / 오늘 한 일 한 문장씩 1주간 쓰기
- [ ] Ten Things I Like / 좋아하는 것 열 가지를 완전한 문장으로 쓰기
- [ ] Question Sentences / 궁금한 것 다섯 개를 의문문으로 쓰기

# PART 2 · Everyday Writing (B1)

## 3. Diary

- [ ] Diary Week / 영어 일기 하루 세 문장 이상 1주 연속
- [ ] Feelings Entry / 사실 나열 말고 감정과 이유가 든 일기 한 편
- [ ] Past and Future / 어제 일과 내일 계획을 한 편에 같이 쓰기
- [ ] Weekly Highlight / 한 주에서 가장 기억나는 일 한 편으로 쓰기
- [ ] Diary Month / 일기 루틴 한 달 유지 `추천`

## 4. Messages and Comments

- [ ] Text Message Set / 약속 잡기·거절·감사 문자 세 통 쓰기
- [ ] Real Comments / 영어 영상·글에 실제 댓글 세 개 달기
- [ ] Reply Thread / 받은 메시지를 가정하고 답장 주고받기 이어 쓰기
- [ ] Social Post / SNS용 짧은 영어 글 하나 완성

## 5. Summaries

- [ ] Story Summary / 읽거나 본 이야기 한 편을 다섯 문장으로 요약
- [ ] News Recap / 기사 하나를 세 문장으로 요약
- [ ] Video Summary / 본 영상 하나 내용을 한 문단으로 정리
- [ ] One Sentence Shrink / 다섯 문장 요약을 다시 한 문장으로 압축

# PART 3 · Structured Writing (B2)

## 6. Paragraph Structure

- [ ] Opinion Paragraph / 좋아하는 것 하나에 대해 찬성 근거 세 개로 한 문단 쓰기
- [ ] Topic Sentence Drill / 주제문 하나 쓰고 뒷받침 문장 세 개 붙이기
- [ ] Example Insertion / 주장에 구체 예시 하나 이상 넣어 문단 완성
- [ ] Counter Paragraph / 같은 주제를 반대 입장에서 한 문단 더 쓰기
- [ ] Paragraph Rewrite / 예전에 쓴 문단 하나 골라 구조 잡아 다시 쓰기

## 7. Formal Email

- [ ] Inquiry Email / 문의 이메일 격식체로 한 통 쓰기
- [ ] Request Email / 부탁·요청 이메일을 완곡한 표현으로 쓰기
- [ ] Complaint Email / 항의 이메일을 정중한 톤 유지하며 쓰기
- [ ] Apology and Thanks / 사과 이메일·감사 이메일 각 한 통 쓰기
- [ ] Cover Message / 지원·자기소개 메일 한 통 완성

## 8. Reviews

- [ ] Product Review / 실제 쓰는 물건 리뷰 한 편 쓰기
- [ ] Media Review / 영화나 책 리뷰를 스포일러 없이 한 편 쓰기
- [ ] Place Review / 가 본 곳 리뷰를 장단점 나눠 쓰기
- [ ] Posted Review / 쓴 리뷰 하나를 실제 사이트에 올리기 `선택`

# PART 4 · Long-Form Writing (C1)

## 9. Essay

- [ ] Essay Outline / 주제 정해 서론-본론-결론 개요 짜기
- [ ] Five Paragraph Essay / 개요대로 5문단 에세이 한 편 완성
- [ ] Argument Essay / 반론 소개와 재반박까지 포함한 찬반 에세이 쓰기
- [ ] Timed Essay / 30분 제한 걸고 에세이 한 편 완성

## 10. Revision

- [ ] Feedback Round / 쓴 글 하나를 사람이나 AI에게 첨삭 받기
- [ ] Rewrite After Feedback / 지적 사항 반영해 같은 글 고쳐쓰기 `추천`
- [ ] Self Edit Pass / 하루 묵힌 글을 스스로 세 군데 이상 고치기
- [ ] Sentence Variety Pass / 길이·구조가 단조로운 문장 찾아 바꿔 쓰기

## 11. Register Control

- [ ] Formal and Casual Pair / 같은 내용을 격식·비격식 두 버전으로 쓰기
- [ ] Audience Shift / 같은 소식을 친구용·상사용으로 각각 다르게 쓰기
- [ ] Tone Softening / 직설적인 문장 다섯 개를 완곡하게 바꿔 쓰기
