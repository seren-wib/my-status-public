# PART 1 · Starting to Read (A1~A2)

## 1. Signs and Labels

- [ ] Street Sign Hunt / 하루 동안 마주친 영어 표지판·간판 10개 뜻 확인하기
- [ ] English Menu Pick / 영어 메뉴판에서 모르는 메뉴 하나 뜻 파악해 골라보기
- [ ] Product Label Read / 집에 있는 수입품 라벨 3개 읽고 용도·주의사항 파악하기
- [ ] Phone in English / 폰 언어를 영어로 바꿔 일주일 버티기 `추천`

## 2. First Readers

- [ ] Picture Book / 영어 그림책 한 권 사전 없이 끝까지 읽기
- [ ] Graded Reader Level 1 / 초급 리더 한 권 끝까지 읽기
- [ ] Korean Retell / 읽은 리더 줄거리를 한국어 3문장으로 요약하기
- [ ] Second Reader Timed / 같은 레벨 한 권 더 읽으며 걸린 시간 기록하기

### Reader Series `택 1`

- [ ] Oxford Bookworms / Starter~1단계에서 시작해 시리즈로 이어 읽기
- [ ] Penguin Readers / Level 1부터 시작해 시리즈로 이어 읽기
- [ ] Cambridge English Readers / Starter부터 시작해 시리즈로 이어 읽기

## 3. Very Short Texts

- [ ] Short Joke Pack / 아주 짧은 영어 농담 5편 읽고 웃긴 포인트 설명하기
- [ ] SNS Post Read / 영어 SNS 게시물 10개 읽고 모르는 표현 적기
- [ ] Chat Log Read / 영어 댓글·단체방 대화 한 흐름 읽고 무슨 상황인지 설명하기
- [ ] Reading Word Log / 읽다 만난 모르는 단어 노트 100개 채우기

# PART 2 · Short Texts (B1)

## 4. Learner News

- [ ] First News Article / 학습자용 뉴스 기사 하나 읽고 한 줄 요약하기
- [ ] Headline Prediction / 헤드라인만 보고 내용 예측 후 본문으로 확인하기
- [ ] Five W Table / 기사 하나에서 누가·언제·어디서·무엇을 표로 뽑기
- [ ] Two-Week News Habit / 학습자용 뉴스 하루 1건 2주 연속 읽기

## 5. Blogs and Forums

- [ ] Hobby Blog Post / 내 취미 분야 영어 블로그 글 한 편 완독하기
- [ ] Forum Thread / 영어 포럼 스레드 하나 읽고 쟁점 파악하기 (예: 레딧)
- [ ] Comment Slang Harvest / 댓글 20개 읽고 슬랭·축약 표현 5개 정리하기
- [ ] How-to Follow / 영어 하우투·레시피 글 보고 실제로 따라 하기

## 6. Intermediate Readers

- [ ] Graded Reader Level 3 / 중급 리더 한 권 완독하기
- [ ] Chapter Summary Run / 챕터마다 영어 한 문장 요약 달며 한 권 읽기
- [ ] Context Guess Routine / 모르는 단어를 문맥으로 추측 후 확인하는 방식으로 한 권 읽기
- [ ] Second Word Log / 단어 노트 100개 더 채워 200개 만들기

# PART 3 · Practical Reading (B2)

## 7. Authentic Articles

- [ ] First Original Article / 원어민 대상 기사 원문 하나 완독하기
- [ ] Two-Source Compare / 같은 사건을 두 매체 기사로 읽고 논조 차이 말하기
- [ ] Fact vs Opinion / 기사에서 사실 문장과 의견 문장 구분해 표시하기
- [ ] Weekly Article Routine / 원문 기사 주 3건 한 달 유지하기

## 8. Manuals and Docs

- [ ] Device Manual / 쓰는 기기 영어 설명서 보고 기능 하나 설정 성공하기
- [ ] Official Docs Task / 영어 공식 문서만 보고 설치·설정 하나 끝내기
- [ ] Help Center Solve / 영어 FAQ·헬프센터에서 내 문제 답 찾아 해결하기
- [ ] Terms Scan / 영어 약관에서 환불·해지 조항만 찾아 읽기

## 9. Easy Fiction

- [ ] Young Adult Novel / 쉬운 원서 소설 한 권 완독하기 (예: YA·아동청소년물)
- [ ] No-Dictionary Chapter / 사전 없이 한 챕터 읽고 이해한 만큼 줄거리 말하기
- [ ] Character Map / 읽는 소설 인물 관계도 그리며 완독하기
- [ ] Reading Speed Check / 원서 한 페이지 읽는 시간 재고 한 달 뒤 재측정하기

# PART 4 · Deep Reading (C1)

## 10. Essays and Commentary

- [ ] Long-form Essay / 장문 에세이 한 편 읽고 논지 3문장 요약하기
- [ ] Columnist Follow / 칼럼니스트 한 명 정해 5편 읽고 관점 정리하기
- [ ] Counter-argument Hunt / 논평 읽으며 반박 가능한 지점 2개 적기
- [ ] Editorial Compare / 같은 이슈 사설 두 편 입장 비교하기

## 11. Full Novels

- [ ] First Full Novel / 원어민 대상 소설 한 권 완독하기
- [ ] Genre Switch Novel / 다른 장르 원서 한 권 더 완독하기
- [ ] Annotated Read / 밑줄·메모 달며 원서 한 권 읽기 `선택`

## 12. Professional Reading

- [ ] English-Only Docs Study / 전공·개발 문서 하나를 번역 없이 원문으로 학습하기
- [ ] Abstract Sprint / 관심 분야 논문 초록 5편 읽고 각 한 줄 요약하기
- [ ] Full Paper Read / 논문 한 편 처음부터 끝까지 읽기
- [ ] English Search Habit / 궁금한 것을 영어로 검색해 영어 자료로 해결 10회 하기

# PART 5 · A Native Reader (C2)
