# Speaking `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-26

# PART 1 · Making Sounds (A1~A2)

## 1. Reading Aloud

- [ ] First Read-Aloud / 쉬운 지문 열 문장 소리내어 읽어 첫 녹음 남기기
- [ ] Daily Read-Aloud Week / 하루 한 지문 소리내어 읽기 1주 연속, 녹음 보관
- [ ] Self Playback / 내 녹음 다시 들으며 뭉개진 단어 표시하고 그 부분만 재녹음
- [ ] Slow to Normal / 같은 지문을 느리게 한 번·보통 속도 한 번 녹음해 비교

## 2. First Recordings

- [ ] One Minute Self-Intro / 1분 자기소개 녹음해 남기기
- [ ] Greeting Variations / 인사·안부 주고받기 5가지 상황별로 녹음
- [ ] Friend Introduction / 가족·친구 한 명 소개 30초 녹음
- [ ] Numbers Out Loud / 날짜·시간·가격 말하는 연습 녹음으로 남기기
- [ ] Self-Intro Retake / 한 달 뒤 자기소개 재녹음해 첫 녹음과 비교

## 3. Survival Scripts

- [ ] Ordering Script / 카페·식당 주문 대본 만들어 소리내어 3회 연습
- [ ] Direction Asking / 길 묻고 답 되묻는 대본 만들어 녹음
- [ ] Shopping Script / 가격·사이즈 묻고 교환 요청하는 대본 연습 후 녹음
- [ ] Hotel Check-in / 체크인·체크아웃 상황 대본 녹음
- [ ] Emergency Phrases / 도움 요청·몸 아픈 상황 표현 대본 소리내어 연습
- [ ] Script Without Paper / 대본 없이 주문 상황 처음부터 끝까지 녹음 `추천`

# PART 2 · Speaking in Sentences (B1)

## 4. Describing

- [ ] Picture Description / 사진 한 장 보고 보이는 것 다섯 문장 녹음
- [ ] Daily Routine / 내 하루 일과를 아침부터 밤까지 순서대로 녹음
- [ ] Room Tour / 내 방을 돌며 물건들 영어로 설명하는 녹음
- [ ] Yesterday Recap / 어제 있었던 일 과거형으로 1분 녹음
- [ ] Weather and Plans / 오늘 날씨와 계획 30초씩 1주간 녹음

## 5. Questions and Answers

- [ ] Question Making / 한 주제로 질문 열 개 만들어 소리내어 읽기
- [ ] Self Q&A / 만든 질문에 스스로 답하는 녹음 남기기
- [ ] Interview Simulation / 자주 받는 질문(취미·전공·계획) 답변 녹음
- [ ] Follow-up Chain / 답 하나에 꼬리 질문 세 개 이어 붙여 녹음

## 6. Phone Simulation

- [ ] Reservation Call / 식당 예약 통화 대본으로 혼자 양쪽 역할 녹음
- [ ] Appointment Change / 약속 변경·취소 통화 시뮬레이션 녹음
- [ ] Voicemail Message / 용건 남기는 음성 메시지 30초 녹음
- [ ] AI Voice Call / 음성 AI와 통화형 대화 5분 해보고 막힌 부분 기록

# PART 3 · Building Flow (B1~B2)

## 7. Shadowing

- [ ] Shadowing Start / 영상 하나 골라 30초 구간 문장별로 따라 말하기
- [ ] Shadowing Week / 같은 구간 1주 반복, 첫날·마지막날 녹음 비교 `추천`
- [ ] Material Rotation / 소재 바꿔가며 섀도잉 루틴 한 달 유지
- [ ] Speed Matching / 원본 속도에 겹쳐 말하기 성공할 때까지 반복

## 8. Impromptu Speaking

- [ ] One Minute Topic / 무작위 주제로 준비 없이 1분 말하기 녹음
- [ ] Three Minute Talk / 익숙한 주제로 3분 끊기지 않고 말하기 녹음
- [ ] Filler Count / 내 녹음에서 음·어 개수 세고 재녹음으로 줄이기
- [ ] Daily Vlog Week / 하루 1분 영어 브이로그식 녹음 1주 연속

## 9. Opinions

- [ ] Opinion Plus Reasons / 찬반 주제 하나에 입장과 이유 두 개 녹음
- [ ] Both Sides / 같은 주제를 반대 입장에서도 1분 녹음
- [ ] Comparison Talk / 두 가지 비교해 어느 쪽이 나은지 근거 대며 녹음
- [ ] Instant Reaction / 뉴스·영상 하나 보고 즉석 감상 1분 녹음

# PART 4 · Logic and Persuasion (B2~C1)

## 10. Debate

- [ ] Debate Prep Notes / 토론 주제 하나 골라 주장·근거·예상 반론 메모
- [ ] Solo Debate / 혼자 찬성·반대 번갈아 맡아 토론 한 편 녹음
- [ ] Rebuttal Drill / 반론 문장 듣고 즉석에서 재반박하는 녹음
- [ ] Live Debate / 사람이나 AI 상대로 실시간 토론 한 판 뒤 녹음 복기

## 11. Presentation

- [ ] Five Minute Presentation / 아는 주제로 5분 발표 준비해 녹음
- [ ] Keyword-only Delivery / 같은 발표를 대본 없이 키워드만 보고 재녹음
- [ ] Q&A Handling / 발표 뒤 예상 질문 세 개에 즉석 답변 녹음
- [ ] Playback Review / 발표 녹음 듣고 고칠 점 세 개 적어 재녹음

## 12. Storytelling

- [ ] Story Retelling / 읽은 이야기나 영화 줄거리 내 말로 재구성해 녹음
- [ ] Personal Story / 내 경험담 하나를 기승전결로 3분 녹음
- [ ] Same Story Two Ways / 같은 이야기를 친구용·격식용 두 버전으로 녹음
- [ ] Pacing Control / 속도·멈춤 조절해 긴장감 살린 버전 재녹음 `선택`

# PART 5 · A Native Tongue (C2)

## 13. Accent and Linking

- [ ] Minimal Pair Retake / 헷갈리는 발음 쌍 녹음해 원어민 소리와 비교 교정
- [ ] Linking Overlay / 연음 구간 표시한 문장을 원본에 겹쳐 녹음 비교
- [ ] Intonation Copy / 원어민 억양 곡선 따라 한 문단 녹음, 원본과 나란히 듣기
- [ ] First versus Now / 첫 자기소개 녹음과 지금 녹음 비교해 변화 기록

## 14. Humor and Play

- [ ] Joke Delivery / 영어 농담 하나 외워 타이밍 살려 녹음
- [ ] Pun Attempt / 말장난 하나 직접 만들어 대화 문맥에 끼워 녹음
- [ ] Sarcasm Tone / 같은 문장을 진심·비꼼 두 톤으로 녹음해 차이 내기
- [ ] Improv Riff / 무작위 단어 세 개로 즉흥 유머 이야기 1분 녹음

## 15. Real Conversations

- [ ] Native Session / 원어민과 30분 대화(전화·화상·대면) 뒤 녹음 복기
- [ ] Stuck Phrase Redo / 대화에서 막혔던 표현 적어 다시 말해보는 녹음
- [ ] Group Discussion / 3인 이상 영어 대화에 끼어 발언하고 복기
- [ ] Disagreement Talk / 원어민과 의견 갈리는 주제로 대화 끝까지 지속
- [ ] Monthly Native Routine / 원어민 대화 월 2회 이상 3개월 유지 `추천`
