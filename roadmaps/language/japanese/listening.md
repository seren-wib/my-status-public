# Listening `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-26

# PART 1 · Opening the Ear (N5)

## 1. Kana Ear Training

- [ ] Kana Word Dictation / 가나 단어 20개 듣고 받아쓰기, 정답과 대조
- [ ] Long Vowel Check / 장음 유무만 다른 단어쌍(おばさん·おばあさん) 듣고 구분해 적기
- [ ] Small Tsu Detection / 촉음 있는 단어·없는 단어 섞어 듣고 받아쓰기
- [ ] Minimal Pair Drill / びょういん·びよういん처럼 헷갈리는 쌍 10개 듣고 구분

## 2. Numbers and Time

- [ ] Number Dictation / 무작위 숫자 20개 듣고 아라비아 숫자로 받아적기
- [ ] Price Listening / 가격 표현 10개 듣고 금액 적기
- [ ] Time and Date / 시각·요일·날짜 듣고 받아적기 10개
- [ ] Phone Number Catch / 전화번호 5개 듣고 받아적기
- [ ] Counter Listening / 개수·인원 표현 듣고 수량만 골라 적기

## 3. Slow Learner Dialogues

- [ ] Slow Dialogue Gist / 학습자용 느린 대화 듣고 상황·화자 관계 한 줄 요약
- [ ] Question Catch / 대화 속 질문문만 골라 받아적기
- [ ] Repeat Listening / 같은 느린 대화 3회 반복해 안 들리던 단어 채우기
- [ ] Greeting Recognition / 대화에 나온 인사·맞장구 표현 들리는 대로 목록화
- [ ] Daily Routine Audio / 하루 일과 설명 음성 듣고 시간 순서로 정리

# PART 2 · With Subtitles (N4)

## 4. Watching with Japanese Subs

- [ ] JP Sub Episode / 애니 1화를 일본어 자막으로 완주
- [ ] Drama JP Sub Episode / 일상 드라마 1화를 일본어 자막으로 완주
- [ ] Known Word Spotting / 시청 중 아는 단어 들릴 때마다 표시, 화당 개수 기록
- [ ] Sub First Audio Second / 자막 먼저 읽고 소리를 예상한 뒤 재생해 확인
- [ ] Weekly Sub Watching / 일본어 자막 시청 주 2회를 4주 유지 `추천`

## 5. Easy Line Dictation

- [ ] Anime Line Dictation / 애니 한 장면 대사 받아적고 자막과 대조
- [ ] Ten Line Transcript / 짧은 장면 10줄 받아쓰기, 오답 유형 기록
- [ ] Blind First Pass / 자막 끄고 먼저 받아적은 뒤 자막 켜서 채점
- [ ] Catchphrase Collection / 캐릭터 말버릇 5개 받아적어 표현 덱에 추가

## 6. Learner Podcasts

- [ ] Learner Podcast Episode / 학습자용 팟캐스트 1편 완청, 주제 한 줄 요약
- [ ] Script Comparison / 스크립트 있는 에피소드 듣고 안 들린 구간 대조
- [ ] Speed Ladder / 같은 에피소드를 0.8배속→1배속 순서로 다시 듣기
- [ ] Podcast Routine / 주 3회 팟캐스트 청취를 2주 유지

# PART 3 · Dropping the Subtitles (N3)

## 7. Removing Subtitles

- [ ] Raw Rewatch / 자막으로 봤던 에피소드 무자막 재시청, 이해도 비교
- [ ] Scene Summary Check / 무자막으로 한 장면 보고 요약, 자막 켜서 검증
- [ ] Raw First Sub Second / 새 에피소드를 무자막 먼저 보고 자막으로 2회차 확인
- [ ] Comprehension Percent Log / 무자막 이해도를 %로 기록해 추이 남기기

## 8. Everyday YouTube

- [ ] Vlog Comprehension / 일상 브이로그 1편 무자막 시청 후 내용 요약
- [ ] Tutorial Steps / 요리·튜토리얼 영상 보고 단계를 순서대로 받아적기
- [ ] Auto Sub Hunt / 자동 자막 켜고 오인식된 구간 찾아내기
- [ ] Channel Routine / 일본인 채널 3개 구독해 주간 시청 루틴 만들기

## 9. Dictation Routine

- [ ] Daily Dictation / 하루 2분 분량 받아쓰기를 1주 연속 `추천`
- [ ] Error Pattern Log / 받아쓰기 오답을 유형별(장음·촉음·연독)로 분류해 기록
- [ ] Contraction Catch / ちゃ·じゃ·とく 같은 축약형을 원형과 함께 받아적기
- [ ] Weekly Redictation / 1주 전 자료 다시 받아써 오답 감소 확인

# PART 4 · Real Speed (N2)

## 10. News and Radio

- [ ] Easy News Audio / 쉬운 뉴스 음성 듣고 육하원칙으로 정리
- [ ] Regular News Segment / 정규 뉴스 한 꼭지 듣고 요지 한 줄 요약
- [ ] Radio Half Hour / 라디오 방송 30분 흘려듣고 기억나는 화제 목록화
- [ ] News Dictation / 뉴스 한 문단 받아쓰기, 한자어 청취 오답 정리

## 11. Interviews

- [ ] Full Interview / 10분 이상 인터뷰 영상 무자막 완청
- [ ] Answer Prediction / 질문 듣고 일시정지, 답을 예상한 뒤 이어 듣기
- [ ] Opinion Extraction / 화자의 주장과 근거를 나눠 메모
- [ ] Multi Speaker Talk / 3인 이상 대담에서 화자별 입장 구분해 적기

## 12. Dramas at Full Speed

- [ ] New Drama Raw / 처음 보는 드라마 1화 무자막 시청, 인물 관계도 그리기
- [ ] Emotional Scene Dictation / 빠르고 뭉개지는 감정 장면 대사 받아적기
- [ ] Genre Rotation / 장르 3개(일상·수사·직장 등) 돌아가며 무자막 시청
- [ ] Weekly Raw Routine / 주 1화 무자막 시청을 4주 유지

# PART 5 · A Native Ear (N1 · Beyond)

## 13. Variety and Comedy

- [ ] Variety Show Raw / 예능 1편 무자막 시청, 웃음 포인트 이해 여부 기록
- [ ] Manzai Comprehension / 만담 한 편 듣고 보케·츳코미 구조 파악해 메모
- [ ] Telop Off Challenge / 화면 자막(텔롭) 가리고 소리만으로 예능 장면 이해
- [ ] Overlapping Banter / 여러 명이 겹쳐 말하는 구간에서 누가 뭐라 했는지 받아적기

## 14. Dialects

- [ ] Kansai Recognition / 간사이 말투 장면 골라 표준어와 다른 점 3개 적기
- [ ] Dialect Speaker Guess / 화자 말투 듣고 지역 추정 후 확인
- [ ] Dialect Line Dictation / 방언 대사 받아적고 표준어로 옮겨보기 `선택`

## 15. Fast Talk and Rough Audio

- [ ] Phone Quality Audio / 전화 음질의 좁은 소리로 대화 듣고 내용 요약
- [ ] Noisy Street Interview / 소음 낀 거리 인터뷰 듣고 핵심 잡기
- [ ] Native Chat Podcast / 원어민 잡담 팟캐스트 1편 무자막 완청
- [ ] Announcement Catch / 역·기내 안내방송 듣고 시간·플랫폼 정보 받아적기
- [ ] Live Stream Follow / 생방송 라이브 30분 듣고 흐름 따라가기
