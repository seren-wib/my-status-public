# PART 1 · Reading Kana (N5)

## 1. Kana Sentences

- [ ] Hiragana Only Sentences / 히라가나만으로 된 짧은 문장 10개 소리내어 읽기
- [ ] Katakana Loanword Reading / 가타카나 외래어 20개 읽고 원어 맞히기
- [ ] Long Vowel Small Tsu / 장음·촉음·요음 든 단어 골라 소리내어 구분해 읽기
- [ ] Kana Paragraph Fluency / 가나 문단 하나를 막힘 없이 읽을 때까지 반복
- [ ] Handwritten Kana Reading / 손글씨체·변형 폰트로 된 가나 읽어보기

## 2. Picture Books

- [ ] First Picture Book / 후리가나 그림책 한 권 소리내어 완독
- [ ] Second Picture Book / 두 번째 그림책은 모르는 단어 표시하며 읽기
- [ ] Korean Retell / 읽은 그림책 줄거리를 한국어로 요약해 말하기
- [ ] Longer Picture Book / 글밥 많은 동화책 한 권 완독

## 3. Signs and Menus

- [ ] Menu Reading / 일본 음식점 메뉴판 사진 보고 주문할 메뉴 고르기
- [ ] Sign Photo Set / 간판·표지판 사진 10장 모아 읽어보기
- [ ] Station Map Reading / 노선도·역명판에서 지명 10개 찾아 읽기
- [ ] Package Label Reading / 과자·음료 포장 문구 읽고 뜻 추측하기
- [ ] Onomatopoeia Spotting / 그림책·광고에서 의성어·의태어 5개 찾아 소리내어 읽기

# PART 2 · With Furigana (N4)

## 4. Furigana Manga

- [ ] First Manga Volume / 후리가나 만화 1권 완독
- [ ] Dialogue Acting / 좋아하는 장면 대사를 소리내어 연기하며 읽기
- [ ] Genre Switch Volume / 다른 장르 후리가나 만화 1권 더 완독

## 5. Easy News

- [ ] Easy News Article / 학습자용 쉬운 뉴스(NHK Easy류) 기사 1편 읽고 한 줄 요약

- [ ] News Retell / 읽은 기사를 안 보고 말로 재구성하기
- [ ] Headline First Guess / 제목만 보고 내용 추측 후 본문 읽어 확인 5회

## 6. Game and App Text

- [ ] Game Dialogue Session / 일본어로 설정한 게임 대사 30분 읽으며 진행

- [ ] Quest Instruction Test / 퀘스트 지시문만 읽고 번역 없이 목표 수행
- [ ] Choice Dialogue Reading / 선택지 대사 읽고 의도한 분기 고르기
