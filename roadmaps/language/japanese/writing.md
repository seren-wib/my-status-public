# PART 1 · Warming Up the Hand (N5)

## 1. Tracing and Copying

- [ ] Kana Handwriting / 히라가나·가타카나 전부 손으로 써 한 장 완성
- [ ] Name Kanji Copying / 내 이름·주소에 쓰는 한자 따라 쓰기
- [ ] Sentence Copying / 교재 예문 10개 필사
- [ ] Typing Setup / 일본어 입력기 설치해 가나 문장 타이핑 연습
- [ ] Genkouyoushi Practice / 원고지 양식 규칙에 맞춰 한 단락 옮겨 쓰기 `선택`

## 2. My Information Sentences

- [ ] Self Data Sentences / 이름·나이·직업·사는 곳을 문장으로 완성해 쓰기
- [ ] Like and Dislike / 좋아하는 것·싫어하는 것 각 3문장 쓰기
- [ ] Weekly Schedule Sentences / 내 일주일 일정을 문장 7개로 쓰기
- [ ] Form Filling / 회원가입식 간단한 양식을 일본어로 채우기

## 3. Three Sentence Self Introduction

- [ ] Three Sentence Intro / 세 문장 자기소개 완성해 남기기
- [ ] Intro Expansion / 자기소개에 취미 문장 하나 덧붙여 다시 쓰기
- [ ] Handwritten Card / 자기소개를 손글씨 카드 한 장으로 정서

# PART 2 · Everyday Writing (N4)

## 4. Japanese Diary

- [ ] First Diary Entry / 오늘 일기 3문장을 일본어로 쓰기
- [ ] One Week Diary / 일기 1주 연속 쓰기 `추천`
- [ ] Past Tense Diary / 어제 일기를 과거형만으로 다시 쓰기
- [ ] Diary Self Correction / 1주치 일기 다시 읽고 이상한 문장 스스로 고치기

## 5. SNS Short Posts

- [ ] First JP Post / 일본어로 SNS 짧은 글 1개 올리기(비공개 가능)
- [ ] Photo Caption / 사진에 일본어 캡션 달기 5회
- [ ] Tone Imitation / 일본 SNS 말투 관찰해 비슷한 톤으로 한 줄 쓰기
- [ ] Reply Writing / 일본어 게시물에 댓글 한 줄 달아보기

## 6. Messages

- [ ] Chat Exchange / 메신저로 일본어 대화 10턴 주고받기
- [ ] Invitation Set / 약속 제안·수락·거절 메시지 세트 쓰기
- [ ] Thanks and Apology / 감사·사과 짧은 메시지 각 1개 쓰기
- [ ] Late Notice / 늦는다고 알리는 메시지를 상대별(친구·격식)로 2개 쓰기

# PART 3 · Structured Writing (N3)

## 7. Paragraph with Claim

- [ ] Claim Paragraph / 주장 1개+이유 2개 구조로 문단 하나 쓰기
- [ ] Connector Polish / 접속 표현(だから·しかし 등) 넣어 문단 매끄럽게 고치기
- [ ] Opposing Paragraph / 같은 주제를 반대 주장으로 문단 쓰기
- [ ] Paragraph Routine / 주 2문단 쓰기를 4주 유지

## 8. Review Writing

- [ ] Anime Review / 본 작품 감상문 300자 쓰기
- [ ] Book Review / 읽은 책·만화 감상문 쓰기
- [ ] Place Review / 가게·장소 리뷰를 일본어로 쓰기
- [ ] Emotion Word Swap / 감상문의 반복 표현(面白かった 등)을 다른 감정 표현으로 바꿔 쓰기

## 9. Summarizing

- [ ] Article Summary / 쉬운 기사 한 편을 3문장으로 요약
- [ ] Episode Summary / 에피소드 줄거리를 5문장으로 요약
- [ ] Summary Compression / 내 요약을 절반 길이로 다시 줄이기
- [ ] Summary Comparison / 원문과 대조해 요약에서 빠뜨린 핵심 체크

# PART 5 · A Native Pen (N1 · Beyond)

## 13. Essay
