# PART 1 · Making Sounds (N5)

## 1. Reading Aloud

- [ ] Kana Chart Recording / 오십음도 소리내어 읽고 녹음해 남기기
- [ ] Word Reading / 배운 단어 30개 낭독 녹음, 장음·촉음 위치 확인
- [ ] Sentence Read Aloud / 짧은 문장 10개 낭독 녹음해 모범 음성과 비교
- [ ] Pitch Pair Recording / 표기 같고 악센트 다른 단어쌍(はし 등) 구분해 발음 녹음
- [ ] Tongue Twister / 일본어 빠른말(早口言葉) 하나 매끄러워질 때까지 녹음

## 2. Greetings and Self Introduction

- [ ] Greeting Set Recording / 시간대별 인사 표현 세트 녹음
- [ ] Jiko Shoukai / 1분 자기소개 일본어로 녹음해 남기기
- [ ] Self Intro Retake / 1주 뒤 자기소개 재녹음해 처음 것과 비교
- [ ] Name and Origin / 내 이름·출신을 일본어로 설명하는 녹음

## 3. Situation Scripts

- [ ] Shopping Script / 편의점·가게 상황 대본 쓰고 양쪽 역할 다 녹음
- [ ] Restaurant Order / 주문·계산 상황 대본 연습 녹음
- [ ] Direction Asking / 길 묻기 대본 연습 녹음
- [ ] Script Without Paper / 대본 안 보고 같은 상황 재연 녹음 `추천`

# PART 2 · Speaking in Sentences (N4)

## 4. Daily Narration

- [ ] Daily Routine Recording / 내 하루 일과를 5문장 이상 말해 녹음
- [ ] Yesterday Recap / 어제 한 일을 과거형으로 말해 녹음
- [ ] Photo Description / 사진 한 장 보고 30초 묘사 녹음
- [ ] Room Description / 지금 있는 공간을 30초 묘사 녹음
- [ ] Narration Routine / 하루 1분 일과 녹음을 1주 연속

## 5. Questions and Answers

- [ ] Question Making / 한 주제로 질문 10개 만들어 소리내 녹음
- [ ] Self QA / 스스로 질문하고 답하는 1인 2역 녹음
- [ ] Instant Response / 흔한 질문(취미·주말 계획) 듣고 즉답 녹음
- [ ] Follow-up Drill / 상대 답에 되묻는 후속 질문 연습 녹음

## 6. Phone Simulation

- [ ] Reservation Call / 식당 예약 전화 시뮬레이션 녹음
- [ ] Appointment Change / 약속 변경 통화 상황 녹음
- [ ] Voice Message / 부재중 음성 메시지 남기기 연습 녹음
- [ ] Call Opening Closing / 전화 첫마디·끝맺음 표현 세트 녹음

# PART 3 · Building Flow (N3)

## 7. Shadowing Routine

- [ ] First Shadowing / 학습자용 음성 한 단락 섀도잉 녹음, 원음과 겹쳐 듣기
- [ ] Daily Shadowing / 하루 10분 섀도잉을 2주 유지 `추천`
- [ ] Drama Line Shadowing / 드라마 한 장면 섀도잉해 억양까지 복사
- [ ] Shadowing Self Check / 내 섀도잉에서 원음과 다른 부분 3개 찾아 교정 재녹음

## 8. Impromptu Speaking

- [ ] One Minute Topic / 무작위 주제로 즉흥 1분 말하기 녹음
- [ ] Three Minute Extension / 같은 주제를 3분으로 늘려 녹음
- [ ] Filler Replacement / 녹음 듣고 한국어 필러를 あの·えっと로 바꿔 재녹음
- [ ] Impromptu Routine / 즉흥 말하기 녹음 주 3회를 4주 유지

## 9. Opinions with Reasons

- [ ] Opinion Statement / 찬반 주제 하나 골라 의견+이유 2개 말해 녹음
- [ ] Comparison Talk / 두 가지를 비교해 어느 쪽이 좋은지 근거와 함께 녹음
- [ ] Experience Support / 의견을 내 경험담으로 뒷받침해 녹음
- [ ] Counter Position / 같은 주제를 반대 입장으로도 말해 녹음 `선택`

- [ ] Refusal Roleplay / 완곡하게 거절하는 상황극 녹음
- [ ] Apology and Thanks / 사과·감사를 정중체로 전하는 녹음
- [ ] Register Switch / 같은 내용을 반말→정중체→경어 3버전으로 녹음 `추천`

## 11. Presentation

- [ ] Three Minute Presentation / 3분 발표 원고 만들어 녹음
- [ ] No Script Delivery / 원고 없이 키워드만 보고 같은 발표 재녹음
- [ ] Timed Delivery / 시간 재서 3분 안에 맞춰 발표 녹음
- [ ] QA Handling / 예상 질문 3개에 답하는 녹음

## 12. Story Retelling

- [ ] Anime Plot Retelling / 본 에피소드 줄거리를 2분으로 재구성해 녹음
- [ ] News Retelling / 읽은 뉴스 내용을 내 말로 요약해 녹음
- [ ] Personal Story / 내 경험담 하나를 기승전결로 말해 녹음
- [ ] Retell Compression / 같은 이야기를 더 짧고 매끄럽게 재녹음

# PART 5 · A Native Tongue (N1 · Beyond)

## 13. Accent Refinement

- [ ] Native Overlay Comparison / 원어민 음성과 내 녹음 겹쳐 듣고 억양 차이 표시
- [ ] Pitch Accent Correction / 자주 틀리는 악센트 단어 10개 교정 녹음
- [ ] Long Passage Prosody / 긴 단락 낭독해 끊어읽기·리듬을 원음과 비교
- [ ] Emotion Variation / 같은 문장을 감정 3가지로 바꿔 낭독 녹음
- [ ] Monthly Archive Review / 월별 녹음 모아 듣고 변화 기록

## 14. Casual Flow

- [ ] Aizuchi Practice / 맞장구(そうなんだ·たしかに)를 타이밍 맞춰 넣는 연습 녹음
- [ ] Contraction Talk / 축약형(ちゃう·とく) 섞은 잡담체 독백 녹음
- [ ] Quick Response / 상황에 한 마디 받아치는 반응 연습 녹음

## 15. Real Conversation

- [ ] Language Exchange Session / 원어민과 30분 대화하고 녹음 복기
- [ ] Conversation Review / 대화 중 막힌 표현 5개 뽑아 다시 말해 녹음
- [ ] Real Phone Call / 실제 일본어 전화(문의 등) 한 통 걸고 복기
- [ ] Monthly Real Talk / 원어민 대화 월 2회 이상을 3개월 유지
