# Character `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. Desire

- [ ] Want and Need / 겉으로 원하는 것과 실제로 필요한 것을 두 줄로 갈라 적기
- [ ] Concrete Goal / 추상적 소망을 손에 잡히는 목표 하나로 바꾸기
- [ ] Motive Backstory / 그 욕망이 생긴 과거 사건 한 장면 쓰기
- [ ] Obstacle Fit / 그 인물만 걸려 넘어질 장애물 설계

## 2. Flaw and Contradiction

- [ ] Defining Flaw / 스스로 못 보는 결함 하나 정하고 증상 세 개 적기
- [ ] Self-Deception / 인물이 스스로에게 하는 거짓말 한 문장
- [ ] Contradiction Pair / 서로 어긋나는 두 성질을 한 인물에 심고 한 장면으로 보이기
- [ ] Moral Line / 절대 넘지 않으려는 선을 정하고 시험하는 장면 쓰기

## 3. Arc

- [ ] Arc Endpoints / 시작 상태와 끝 상태를 각 한 문장으로 못박기
- [ ] Turning Beats / 변화가 일어나는 지점 세 개를 장면으로 배치
- [ ] Cost of Change / 변하기 위해 버린 것을 결말에서 드러내기
- [ ] Flat Arc Variant / 변하지 않는 인물로 같은 이야기를 다시 짜보기

## 4. Cast Design

- [ ] Foil Character / 주인공의 결함을 비추는 대조 인물 만들기
- [ ] Antagonist Logic / 반대편 인물의 목표를 그쪽 시점에서 정당하게 쓰기
- [ ] Relationship Map / 인물 간 원하는 것·숨기는 것을 한 장 도표로
- [ ] Cast Trim / 역할이 겹치는 인물 둘을 하나로 합쳐보기

## 5. Showing Character

- [ ] Choice Under Pressure / 선택 하나로 성격을 드러내는 장면 쓰기
- [ ] Signature Behavior / 반복되는 습관·물건으로 인물 표시하기
- [ ] Character Interview / 인물에게 질문 열 개를 던지고 그 목소리로 답하기
