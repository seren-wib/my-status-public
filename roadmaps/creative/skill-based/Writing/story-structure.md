# Story Structure `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. Premise and Spine

- [ ] One-Line Premise / 이야기 하나를 한 문장으로 압축해 적기
- [ ] Central Question / 독자가 끝까지 답을 기다릴 질문 한 줄 세우기
- [ ] Stakes / 실패하면 잃는 것을 구체적 대상으로 못박기

## 2. Act Structure

- [ ] Inciting Incident / 일상을 깨는 사건 한 장면 쓰기
- [ ] First Turn / 주인공이 되돌아갈 수 없게 되는 지점 배치
- [ ] Midpoint Reversal / 중간에 목표나 정보가 뒤집히는 장면 쓰기
- [ ] Low Point / 최악의 순간을 한 장면으로 밀어붙이기
- [ ] Climax and Resolution / 중심 질문에 답하는 결말까지 붙이기
- [ ] Three-Act Short / 3막 구조로 단편 초고 한 편 완성

## 3. Sequence and Causality

- [ ] Beat Sheet / 장면 목록을 12~20줄 카드로 늘어놓기
- [ ] Causal Chain / 장면 사이를 '그래서·하지만'으로 연결해 점검
- [ ] Setup and Payoff / 심어둔 요소 세 개를 뒤에서 회수하기
- [ ] Subplot Weave / 부플롯 하나를 본줄기에 교차 배치

## 4. Tension and Pacing

- [ ] Tension Curve Map / 장면별 긴장도를 0~10으로 그래프에 찍어보기
- [ ] Scene and Sequel Rhythm / 사건 장면과 여파 장면을 번갈아 배치
- [ ] Withholding Information / 정보 공개 순서를 바꿔 긴장 유지하기
- [ ] Deadline Pressure / 시한을 넣어 같은 초고를 조여보기

## 5. Alternative Shapes

- [ ] Nonlinear Order / 같은 이야기를 시간 순서를 흩어 다시 배열
- [ ] Frame Story / 액자 구조로 도입·결말 감싸기
- [ ] Structure Autopsy / 좋아하는 작품 하나를 장면 단위로 해부해 표로 정리
