# Revision `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. Getting Distance

- [ ] Cooling Period / 초고를 일주일 묵힌 뒤 처음부터 읽기
- [ ] Read-Through Notes / 고치지 말고 끝까지 읽으며 여백에만 메모 남기기
- [ ] Format Change Read / 인쇄·글꼴 변경 상태로 읽어 익숙함 깨기

## 2. Structural Diagnosis

- [ ] Reverse Outline / 완성 원고에서 장면 목록을 거꾸로 뽑아 표로
- [ ] Scene Justification / 장면마다 존재 이유를 한 줄로 적고 못 적으면 표시
- [ ] Tension Recheck / 뽑은 표에 긴장도를 찍어 처지는 구간 찾기
- [ ] Reorder Experiment / 장면 순서를 바꿔 한 판 다시 배열해보기

## 3. Cutting

- [ ] Ten Percent Cut / 분량을 10% 줄이되 사건은 그대로 유지
- [ ] Kill the Darling / 아까운 장면 하나를 실제로 들어내고 앞뒤 잇기
- [ ] Redundancy Sweep / 같은 정보를 두 번 말한 곳 찾아 하나 지우기
- [ ] Opening Surgery / 첫 장면 앞부분을 잘라내고 어디서 시작할지 다시 정하기

## 4. Line Editing

- [ ] Line Pass / 한 쪽씩 문장 단위로 훑으며 군더더기 걷어내기
- [ ] Consistency Check / 이름·시간·설정 어긋남을 목록으로 잡아 수정
- [ ] Proofread Pass / 오탈자·문장부호만 보는 마지막 판 돌리기

## 5. Feedback

- [ ] Targeted Questions / 독자에게 물을 질문 세 개를 정해 원고와 함께 넘기기
- [ ] Reader Report Triage / 받은 피드백을 수용·보류·기각으로 분류
- [ ] Revision Log / 판본별로 무엇을 왜 고쳤는지 기록 남기기
- [ ] Final Version Freeze / 고치기를 멈출 기준을 정하고 원고 확정
