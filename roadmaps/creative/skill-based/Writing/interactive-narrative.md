## 1. Branch Design

- [ ] Branch Map / 선택지 3개짜리 분기도 한 장 설계
- [ ] Node Prototype / 분기 하나를 실제 텍스트로 채워 플레이해보기
- [ ] Gauntlet vs Web / 되돌아 합류하는 구조와 완전 분기 구조로 각각 짜보기
- [ ] Convergence Point / 갈라진 갈래를 다시 모으는 지점 배치
- [ ] Combinatorial Budget / 쓸 수 있는 분량 안에서 분기 수 상한 정하기

## 2. Choice Writing

- [ ] Meaningful Choice / 결과가 실제로 달라지는 선택지 한 세트 쓰기
- [ ] Choice Framing / 선택지 문구만 다듬어 같은 결과를 다르게 느끼게 하기
- [ ] Informed vs Blind / 정보 있는 선택과 도박성 선택을 각각 배치
- [ ] Timed or Silent Choice / 시간 제한·무응답을 하나의 선택으로 설계

## 3. State and Flags

- [ ] Flag Table / 플래그·변수 목록을 표로 만들어 관리
- [ ] Conditional Text / 플래그에 따라 문장이 바뀌는 장면 한 개 구현
- [ ] Relationship Meter / 호감도 같은 수치를 넣고 임계값 분기 만들기
- [ ] State Debug Pass / 플래그 조합을 훑어 도달 불가·모순 상태 찾아내기

## 4. Endings and Replay

- [ ] Multiple Endings / 서로 다른 결말 세 개를 조건과 함께 설계
- [ ] Ending Ownership / 각 결말이 플레이어 선택 탓임을 느끼게 쓰기
- [ ] Replay Incentive / 두 번째 플레이에서만 보이는 정보 심기
- [ ] Route Coverage Test / 모든 결말을 실제로 끝까지 한 번씩 도달해보기

## 5. Production

- [ ] Authoring Tool Draft / Twine 등 도구로 짧은 분기 작품 한 편 완성
