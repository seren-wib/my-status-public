## 1. Sentence and Rhythm

- [ ] Sentence Length Mix / 긴 문장 뒤에 짧은 문장을 붙여 한 단락 다시 쓰기
- [ ] Verb-Driven Sentences / 형용사 기대는 문단을 동사 중심으로 고쳐 쓰기
- [ ] Word Order Emphasis / 강조할 말을 문장 끝으로 옮겨 세 번 고쳐보기
- [ ] Read Aloud Pass / 한 쪽을 소리 내어 읽고 걸리는 지점 표시해 수정
- [ ] Paragraph Shape / 단락 길이를 의도적으로 들쭉날쭉하게 배치

## 2. Point of View

- [ ] POV Choice / 같은 장면을 1인칭·3인칭 제한으로 각각 써서 비교
- [ ] Psychic Distance / 카메라를 멀리서 가까이 당기듯 거리 조절해 쓰기
- [ ] Filtering Words / 보았다·느꼈다 같은 여과 표현을 걷어내고 다시 쓰기
- [ ] POV Consistency Check / 한 장면 안 시점 이탈을 찾아 표시하기
- [ ] Unreliable Narrator / 믿을 수 없는 화자로 짧은 장면 한 편

## 3. Description

- [ ] Concrete Detail / 추상 묘사 한 단락을 감각 가능한 사물로 교체
- [ ] Selective Detail / 세부 세 개만 남기고 나머지 지워 장면 세우기
- [ ] Detail as Character / 같은 방을 두 인물의 눈으로 다르게 묘사하기
- [ ] Figurative Language / 은유·직유를 한 단락에 섞어 쓰되 이미지 계열 통일

## 4. Voice and Diction

- [ ] Register Control / 같은 내용을 격식체·구어체로 각각 쓰기
- [ ] Cliche Hunt / 초고에서 상투구를 찾아 자기 표현으로 갈아끼우기
- [ ] Style Imitation / 좋아하는 작가의 한 쪽을 흉내 내 써보기
- [ ] Personal Voice Statement / 내 문체의 규칙 다섯 줄로 적어두기
