# Color Grading `AI 생성`

## 1. Reading the Image

- [ ] Scope Reading / 파형·벡터스코프를 보며 한 컷을 판정하고 메모 남기기
- [ ] Exposure Fix / 어둡게 찍힌 컷 하나를 정상 노출로 복구하기
- [ ] Clipping Rescue / 하이라이트·섀도가 날아간 구간을 찾아 되살리기

## 2. Primary Correction

- [ ] Neutral White Balance / 색이 틀어진 컷을 회색 기준으로 중립화하기
- [ ] Contrast Shaping / 리프트·감마·게인으로 한 컷의 명암을 잡기
- [ ] Saturation Control / 과채도 컷을 눈에 맞게 낮춰 다시 내보내기
- [ ] Skin Tone Correction / 인물 피부색을 기준선에 맞춰 보정하기

## 3. Building a Look

- [ ] Warm and Cool Pair / 같은 컷을 따뜻한 판과 차가운 판 두 개로 만들기
- [ ] Complementary Look / 보색 대비를 살린 화면 하나 그레이딩하기
- [ ] Secondary Isolation / 특정 색만 골라 바꾼 컷 한 장 만들기
- [ ] Vignette and Focus / 밝기 차로 시선을 한 곳에 몰아준 컷 하나

## 4. Consistency

- [ ] Shot Matching / 다른 조명에서 찍은 두 컷의 색을 맞춰 붙이기
- [ ] Scene-Wide Grade / 한 장면 전체를 하나의 색으로 통일해 내보내기
- [ ] Before and After / 보정 전후 비교본을 만들어 남기기

## 5. Delivery

- [ ] Working Color Space / 소스에 맞는 컬러 스페이스를 잡고 한 편 작업하기
- [ ] Safe Range Export / 범위를 벗어난 값을 잡고 최종 출력하기
- [ ] Cross-Screen Check / 폰과 PC 두 화면에서 확인하고 재보정하기
