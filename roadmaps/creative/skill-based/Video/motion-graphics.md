# Motion Graphics `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. Type on Screen

- [ ] Subtitle Pass / 대사 전체에 자막을 얹어 한 편 완성하기
- [ ] Readable Type / 배경 위에서 읽히는 자막 스타일 하나를 정해 끝까지 유지하기
- [ ] Safe Area / 잘리지 않는 영역 안에 텍스트를 배치해 내보내기
- [ ] Title Card / 작품 제목 카드 한 장 만들기

## 2. Keyframes and Easing

- [ ] First Keyframe Move / 텍스트 하나를 A에서 B로 움직여보기
- [ ] Easing Curve / 같은 이동을 선형과 이즈 두 버전으로 만들어 비교하기
- [ ] Anticipation and Overshoot / 살짝 튕기며 등장하는 애니메이션 하나 만들기
- [ ] Timing to Beat / 음악 박에 맞춰 텍스트를 등장시키기

## 3. Graphics in Motion

- [ ] Text Reveal / 마스크로 글자가 드러나는 등장 하나 만들기
- [ ] Lower Third / 이름표 그래픽을 만들어 실제 영상에 얹기
- [ ] Simple Infographic / 숫자 하나를 움직이는 그래프로 표현하기
- [ ] Transition Element / 화면 전환용 도형 애니메이션 하나 제작하기

## 4. Integration

- [ ] Motion Tracking / 화면 속 물체를 따라다니는 텍스트 붙이기
- [ ] Chroma Key / 크로마키로 배경을 바꾼 컷 하나 만들기
- [ ] Style Consistency / 한 편의 모든 그래픽을 같은 폰트·색으로 통일하기

## 5. Output

- [ ] Render and Compress / 용량과 화질을 타협해 최종 파일 뽑기
- [ ] Alpha Export / 배경 투명한 그래픽으로 내보내 다른 영상에 얹기
- [ ] Loop Export / 끊김 없이 반복되는 짧은 루프 하나 만들기
