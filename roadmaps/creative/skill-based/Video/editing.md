# Editing `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. Assembly

- [ ] Editing Software `택 1` / DaVinci Resolve, Premiere Pro, Final Cut Pro
- [ ] Footage Triage / 소스를 훑고 쓸 컷만 골라 표시해두기
- [ ] Rough Cut / 고른 컷을 순서대로 붙여 러프컷 한 편 만들기
- [ ] One-Minute Cut / 소스 영상을 1분짜리로 컷 편집 한 편

## 2. The Cut Point

- [ ] Cutting on Action / 동작 한가운데서 끊어 두 컷을 이어 붙이기
- [ ] Match Cut / 동작이 이어지는 매치 컷 하나 만들기
- [ ] Jump Cut / 같은 프레임에서 시간을 건너뛰는 구간 하나 편집
- [ ] Eyeline Match / 보는 컷과 보이는 컷을 이어 한 장면 만들기

## 3. Rhythm and Pacing

- [ ] Cut Length Rhythm / 컷 길이만 바꿔 같은 장면을 빠른 판·느린 판 두 개로
- [ ] Music-Driven Edit / 곡의 박에 컷을 맞춘 30초 편집 한 편
- [ ] J-Cut and L-Cut / 소리를 먼저 넘기고 나중에 남겨 두 장면 잇기
- [ ] Tightening / 러프컷 길이를 30퍼센트 줄여 다시 내보내기

## 4. Transitions

- [ ] Hard Cut Default / 트랜지션 없이 컷만으로 한 편 완성하기
- [ ] Dissolve for Time / 시간 경과를 디졸브 한 번으로 표현하기
- [ ] Cutaway and Insert / 컷어웨이를 끼워 점프컷 감추기
- [ ] Montage Sequence / 짧은 컷 묶음으로 경과를 보여주는 몽타주 한 편

## 5. Finishing

- [ ] Opening Ten Seconds / 첫 10초를 세 가지로 다르게 편집해 비교하기
- [ ] Continuity Check / 컷 사이 연결 오류를 목록으로 뽑고 고치기
- [ ] Picture Lock / 수정을 끝내고 픽처 락 버전 한 편 내보내기
