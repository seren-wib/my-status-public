# Shooting `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. Shot Sizes

- [ ] Shot Size Ladder / 같은 피사체를 와이드에서 클로즈업까지 5단계로 찍어 한 줄로 늘어놓기
- [ ] Establishing Shot / 장소를 한 컷으로 설명하는 와이드 한 장 찍기
- [ ] Close-Up on Detail / 손이나 물건 클로즈업으로 감정 한 컷 만들기
- [ ] Over-the-Shoulder Pair / 대화 장면을 어깨너머 두 컷으로 찍어 붙이기

## 2. Angle and Lens

- [ ] Angle Comparison / 같은 인물을 눈높이·하이·로우로 찍어 인상 차이 비교본 남기기
- [ ] Focal Length Test / 광각·표준·망원으로 얼굴 크기 맞춰 찍고 왜곡 차이 기록
- [ ] Shallow Depth of Field / 조리개 열어 배경 날린 인물 컷 한 장
- [ ] 180-Degree Line / 가상선 지킨 대화 장면과 일부러 넘긴 장면을 각각 찍어보기

## 3. Camera Movement

- [ ] Static Frame Discipline / 삼각대 고정 컷만으로 30초 장면 찍기
- [ ] Pan and Tilt / 시작 프레임과 끝 프레임이 둘 다 구도가 되는 팬 한 컷
- [ ] Handheld Follow / 걷는 인물을 따라가는 핸드헬드 한 컷
- [ ] Push In / 인물에게 천천히 들어가며 긴장을 만드는 컷 하나

## 4. Lighting

- [ ] Three-Point Setup / 키·필·백 세 등으로 인물 한 컷 조명해 촬영
- [ ] Key Light Direction / 키 라이트를 정면·측면·역광으로 옮겨 세 컷 찍어 비교
- [ ] Available Light / 창문 빛 하나만으로 실내 인물 촬영
- [ ] Exposure and White Balance / 노출·화이트밸런스를 수동으로 잡아 촬영본 한 편

## 5. Planning the Shoot

- [ ] Shot List / 찍을 컷 목록을 먼저 쓰고 그대로 찍어오기
- [ ] Coverage for Editing / 한 장면을 사이즈 바꿔가며 여러 번 찍어 편집 여지 남기기
- [ ] Location Scout / 촬영 전 장소를 답사해 시간대별 빛을 기록하기
