# Mixing `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. Gain and Balance

- [ ] Gain Staging / 모든 트랙 입력을 정리해 마스터 클립 없이 헤드룸 남기기
- [ ] Static Balance / 플러그인 없이 페이더만으로 한 곡 밸런스 잡아 저장
- [ ] Panning Layout / 파트별 좌우 자리를 정해 패닝하고 모노로 확인
- [ ] Reference Matching / 레퍼런스 곡과 번갈아 들으며 밸런스 차이 메모해 고치기

## 2. EQ

- [ ] Subtractive EQ / 거슬리는 대역을 찾아 깎아 한 트랙 정리하기
- [ ] Low End Cleanup / 킥·베이스 외 트랙의 저역을 잘라 흙탕물 걷어내기
- [ ] Frequency Carving / 겹치는 두 파트 중 하나를 깎아 자리 만들어주기
- [ ] Tonal Shaping / 보컬 한 트랙을 밝게·두껍게 두 버전으로 EQ해 비교

## 3. Dynamics

- [ ] Compression Basics / threshold, ratio, attack으로 드럼 눌러보기
- [ ] Vocal Compression / 보컬 한 트랙을 문장 끝까지 들리게 눌러 저장
- [ ] Parallel Compression / 원본과 강하게 누른 트랙을 섞어 드럼 두껍게 만들기
- [ ] Bus Compression / 그룹 버스에 가볍게 걸어 파트가 붙는지 확인
- [ ] Transient Control / 어택을 살리거나 죽여 같은 소스로 두 버전 만들기

## 4. Space and Depth

- [ ] Reverb Send / 리버브 하나를 센드로 걸어 여러 트랙을 같은 공간에 두기
- [ ] Delay Timing / 템포에 맞춘 딜레이로 빈틈 채우고 마스킹 확인
- [ ] Depth Layering / 앞·중간·뒤 세 겹으로 트랙을 배치해 원근 만들기
- [ ] Stereo Width Check / 폭을 넓힌 뒤 모노 합성해 사라지는 소리 잡기

## 5. Finishing

- [ ] Mix Bus Chain / 마스터에 EQ·컴프·리미터를 걸고 라우드니스 확인
- [ ] Multi-System Check / 이어폰·스피커·폰 스피커 3종에서 듣고 수정 목록 만들기
- [ ] Bounce and Version / 최종 믹스와 대안 믹스를 각각 내보내 보관
