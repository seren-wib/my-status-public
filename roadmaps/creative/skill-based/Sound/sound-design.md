# Sound Design `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. Recording and Foley

- [ ] Field Recording / 밖에서 소리 10종을 녹음해 이름 붙여 라이브러리에 넣기
- [ ] Footstep Foley / 발소리 3종(흙·나무·금속) 직접 녹음해 만들기
- [ ] Prop Substitution / 실제와 다른 물건으로 원하는 소리 만들어내기 (뼈 부러지는 소리 등)
- [ ] Mic Placement / 같은 소리를 근접·거리 두 위치로 녹음해 차이 남기기

## 2. Synthesis

- [ ] Subtractive Patch / 오실레이터·필터·엔벨로프로 레이저 발사음 하나 만들기
- [ ] Noise Based Effects / 노이즈를 깎아 바람·증기·폭발음 만들기
- [ ] FM Metallic Tones / FM으로 금속성 알림음·UI 벨 소리 만들기
- [ ] Envelope Shaping / 같은 소스로 짧은 타격음과 긴 지속음 두 버전 만들기

## 3. Ambience

- [ ] Ambience Bed / 한 장소의 배경음을 30초 루프로 이음새 없이 만들기
- [ ] Layered Environment / 베드·중간층·단발음 3층으로 숲 앰비언스 구성
- [ ] Indoor vs Outdoor / 같은 소스로 실내·야외 두 공간감 버전 만들기
- [ ] Loop Point Editing / 루프 이음새 클릭 없애고 반복 재생으로 검수

## 4. Game and Video SFX

- [ ] UI Sound Set / 클릭·확인·취소·오류 4종 UI 사운드 세트 만들기
- [ ] Impact Layering / 타격음을 어택·바디·꼬리 3레이어로 합성
- [ ] Variation Set / 같은 동작용 변주 5개를 만들어 반복 티 안 나게 하기
- [ ] Sync to Picture / 영상 클립 하나에 효과음을 프레임 단위로 붙이기
- [ ] Asset Naming and Export / 명명 규칙 정해 포맷·길이 맞춰 내보내기
- [ ] Loudness Consistency / 세트 전체 음량을 고르게 맞춰 재검수
