- [ ] Melody Transcription / 좋아하는 곡 후렴 8마디를 귀로 따서 악보나 미디로 옮기기

## 2. Rhythm and Time

- [ ] Metronome Playing / 메트로놈 2·4박에만 맞춰 8마디 치기
- [ ] Time Signature Feel / 4/4·3/4·6/8로 같은 리듬 패턴을 각각 녹음해 비교
- [ ] Subdivision Clapping / 8분·16분·셋잇단을 한 마디씩 이어서 손뼉으로 치기
- [ ] Groove Transcription / 드럼 한 소절을 킥·스네어·하이햇으로 분해해 미디로 재현
- [ ] Syncopation Loop / 강박을 비운 2마디 리듬 루프 만들기

## 3. Chords and Harmony

- [ ] Triad Shapes / 메이저·마이너 3화음을 12키로 짚어 녹음하기
- [ ] Seventh Chords / 7th를 얹은 코드로 같은 진행을 다시 쳐서 색 차이 남기기
- [ ] Diatonic Chords / 한 조의 다이아토닉 코드 7개를 순서대로 짚어 흐름 녹음
- [ ] Chord Function / 곡 하나의 코드를 T·S·D로 표시해 진행표 만들기
- [ ] Voice Leading / 같은 진행을 자리바꿈으로 다시 짚어 최소 이동으로 연결
- [ ] Chord Chart Copy / 아는 곡 한 곡의 코드를 통째로 채보해 반주하기
