# Composing `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. Melody

- [ ] DAW `택 1` / Reaper, FL Studio, Ableton Live, Logic Pro
- [ ] Four-Bar Loop / 코드 진행 위에 4마디 멜로디 루프 하나
- [ ] Motif Development / 2마디 동기 하나를 반복·전위·확대해 8마디로 늘리기
- [ ] Contour Sketch / 같은 코드 위에 상행형·하행형·아치형 멜로디 3개 만들어 고르기
- [ ] Rhythm First Melody / 음정 없이 리듬만 먼저 짜고 뒤에 음을 얹기
- [ ] Singable Range Test / 만든 멜로디를 실제로 불러보고 안 불리는 구간 고치기

## 2. Chord Progression

- [ ] Loop Progression / 4코드 루프 3종을 만들어 각각 위에 같은 멜로디 얹어보기
- [ ] Cadence Endings / 한 곡의 끝을 세 가지 종지로 만들어 비교 녹음
- [ ] Borrowed Chord / 진행 한 자리를 다른 조의 코드로 바꿔 분위기 틀기
- [ ] Bass Movement / 코드 루트를 순차·도약으로 각각 다시 짜서 비교
- [ ] Reharmonization / 자기 멜로디에 코드를 통째로 다시 붙여보기

## 3. Song Sketch

- [ ] Hook First Draft / 후렴 훅 하나를 먼저 만들고 나머지를 붙이기
- [ ] Verse and Chorus Contrast / 벌스와 코러스를 음역·밀도로 갈라 차이 만들기
- [ ] Section Map / 한 곡의 구간 순서를 한 장에 적고 마디 수 채우기
- [ ] Two-Minute Demo / 2분짜리 데모 한 곡을 끝까지 완성해 저장
- [ ] Lyric Sketch / 멜로디에 임시 가사를 붙여 음절 수 맞추기

## 4. Habits

- [ ] Daily Idea Capture / 하루 하나씩 30초 아이디어를 녹음해 모으기
- [ ] Constraint Writing / 3코드·1악기 같은 제약 하나 걸고 한 곡 쓰기
- [ ] Pastiche Study / 좋아하는 곡의 구조만 베껴 다른 멜로디로 한 곡 쓰기
- [ ] Finish Rule / 미완성 스케치 3개를 골라 억지로라도 끝내기
