## 1. Starting Out

- [ ] Walk-Run Intervals / 걷기 4분·뛰기 1분 반복으로 30분 채우기 1회
- [ ] Twice a Week / 주 2회 유산소를 2주 연속 유지
- [ ] Comfort Check / 달린 다음날 무릎·정강이 상태 기록해 강도 조절

## 2. Measuring

- [ ] Cooper Test / 12분 최대 달리기 거리 측정해 첫 기록 남기기
- [ ] Heart Rate Zones / 최대심박 추정치(220-나이)로 내 존2 범위 계산
- [ ] Zone 2 Session / 대화 가능한 강도로 30분 유지 1회
- [ ] Resting Heart Rate / 아침 안정 시 심박수 1주간 측정해 평균 내기

## 3. Building Endurance

- [ ] Weekly Volume / 주간 달리기 시간을 4주에 걸쳐 조금씩 늘리기
- [ ] 5K Finish / 쉬지 않고 5km 완주
- [ ] Route Variety / 코스 2개 이상 만들어 지루함 대비

## 4. Speed and Form

- [ ] Interval Session / 빠르게 1분·천천히 2분 반복 세션 1회
- [ ] Cadence Count / 1분간 발걸음 수 세어 기록, 보폭 줄여 재측정
- [ ] Cooper Retest / 4주 이상 훈련 후 쿠퍼 테스트 재측정해 변화 확인
