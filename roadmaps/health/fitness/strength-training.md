## 1. Bodyweight Foundations

- [ ] Squat Pattern / 맨몸 스쿼트 15개를 거울이나 영상으로 폼 확인하며 수행
- [ ] Push-up Form / 무릎 대고라도 정자세 푸쉬업 10개, 영상 찍어 팔꿈치 각도 확인
- [ ] Plank Hold / 허리 안 꺾인 플랭크 60초 버티기
- [ ] Pull Progression / 철봉 매달리기 30초 또는 인버티드 로우 10개

## 2. Free Weight Basics

- [ ] Hip Hinge / 빈 봉이나 막대로 힙힌지 패턴 15개, 허리 중립 영상 확인
- [ ] Goblet Squat / 덤벨·물통 하나로 고블릿 스쿼트 3세트
- [ ] Big Three First Session / 스쿼트·벤치·데드리프트를 빈 봉으로 각 1세션 폼 연습
- [ ] Safety Setup / 세이프티 바·클립 세팅과 실패 시 탈출 동작을 직접 연습

## 3. Progressive Overload

- [ ] Training Log / 종목·무게·횟수를 매 세션 기록하는 습관 4주 유지
- [ ] Load Progression / 같은 종목 무게나 횟수를 4주에 걸쳐 실제로 올려보기
- [ ] RPE Check / 세트마다 RPE(남은 여력)를 매겨 기록 1주 실행

## 4. Warm-up and Recovery

- [ ] Warm-up Routine / 본 운동 전 5분 워밍업 루틴 만들어 3세션 적용
- [ ] Rest Day Placement / 같은 부위 연속 훈련 피하게 내 주간 휴식일 배치
- [ ] Soreness Journal / 운동 후 통증 부위·정도를 기록해 폼 문제와 근육통 구분
