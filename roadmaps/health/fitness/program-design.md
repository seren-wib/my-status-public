## 1. Principles

- [ ] Weekly Split / 전신·상하체 등 분할 방식 하나 골라 내 주간표에 배치
- [ ] Volume Count / 부위별 주간 세트 수를 세어 표로 정리
- [ ] Cardio Placement / 근력과 유산소가 안 겹치게 주간표에 배치

## 2. My Program

- [ ] Four Week Plan / 내 여건(장소·장비·시간)에 맞는 4주 프로그램 직접 작성
- [ ] Full Execution / 그 프로그램을 4주간 실행하며 세션마다 기록
- [ ] Adherence Review / 계획 대비 실제 수행률 계산하고 빠진 날 원인 적기
- [ ] Revision / 회고 반영해 다음 4주 프로그램 수정판 작성

## 3. Plateau and Deload

- [ ] Deload Week / 4~6주마다 부하 줄이는 주를 계획에 넣어 실행
- [ ] Plateau Response / 정체 시 무게·횟수·빈도 중 변수 하나만 바꿔 2주 관찰
- [ ] Sick Day Rule / 아프거나 바쁠 때 건너뛸지 줄일지 내 규칙 정해두기
