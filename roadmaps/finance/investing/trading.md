# Trading `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-26

## 1. Reading the Chart

- [ ] Candle Log / 실제 차트에서 캔들 모양 5종 찾아 다음 날 결과까지 기록
- [ ] Support and Resistance / 내 관심 종목 차트에 지지·저항선 직접 긋고 이탈 여부 확인
- [ ] Trend Line Draw / 추세선 긋고 돌파·이탈 시점 표시해 기록
- [ ] Volume Confirm / 가격 움직임과 거래량의 관계를 사례 3건으로 검증

## 2. Indicators

- [ ] Moving Average Setup / 이동평균 2개 걸고 교차 시점을 실제 차트에서 표시
- [ ] Oscillator Apply / RSI·MACD를 내 차트에 적용해 신호 10건의 결과 기록
- [ ] Indicator Failure Log / 지표가 틀린 사례 5건 모아 어떤 국면에서 깨지는지 정리

## 3. Rules and Testing

- [ ] Rule in One Sentence / 진입·청산 조건을 한 문장 규칙으로 확정
- [ ] Manual Backtest / 과거 1년 차트에 내 규칙 적용해 거래 30건 손익 집계
- [ ] Paper Trading / 모의로 2주간 규칙대로만 매매하고 승률·손익비 계산
- [ ] Technical Analysis Limits / 기술적 분석의 한계와 비판 확인

## 4. Short-term Cost

- [ ] Turnover Cost Calc / 하루 5회 매매 가정해 한 달 수수료·거래세 총액 계산
- [ ] Slippage Measure / 실제 체결가와 목표가 차이를 10건 모아 평균 산출
- [ ] Scalping Trial / 소액으로 단타 10건 해보고 비용까지 넣어 순손익 결산

## 5. Risk Management

- [ ] Position Sizing / 계좌 대비 1회 위험 비율 정해 주문 수량 계산식 확정
- [ ] Stop-loss Rule / 손절 기준을 숫자로 정해 문서화하고 한 달 지키기
- [ ] Leverage Exposure / 신용·레버리지 상품의 이자와 손실 배수를 내 금액으로 계산
- [ ] Loss Streak Plan / 연속 손실 시 중단 기준 정하고 실제로 멈춰보기
