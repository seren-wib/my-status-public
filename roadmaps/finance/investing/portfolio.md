## 1. Allocation Design

- [ ] Goal and Horizon / 목표 금액·기간을 숫자로 적고 필요 수익률 역산
- [ ] Asset Class Split / 주식·채권·현금 비중을 퍼센트로 확정해 실제 계좌에 맞추기
- [ ] Regional Split / 국내·해외 비중 정하고 현재 보유와의 차이 계산
- [ ] Allocation Style `택 1` / 고정비중, 생애주기형, 위험균형

## 2. Correlation and Risk

- [ ] Correlation Table / 보유 자산 간 상관계수를 과거 데이터로 계산해 표로 정리
- [ ] Concentration Check / 한 종목·한 섹터 비중을 계산하고 상한선 정하기
- [ ] Portfolio Drawdown / 내 배분으로 과거 하락장 손실을 시뮬레이션해 산출
- [ ] Currency Exposure / 환노출 비중 계산하고 환헤지 여부 결정

## 3. Rebalancing

- [ ] Rebalance Rule / 주기 또는 이탈폭 기준을 숫자로 정해 문서화
- [ ] First Rebalance / 실제로 매도·매수해 목표 비중으로 되돌리기
- [ ] Rebalance Cost / 리밸런싱 1회의 수수료·세금을 계산해 주기 재조정
- [ ] Cash Flow Rebalance / 신규 납입금만으로 비중 맞추는 방식 한 번 실행

## 4. Documentation and Review

- [ ] Portfolio Sheet / 보유 자산·비중·매수 근거를 한 장 시트로 정리
- [ ] Quarterly Review / 분기 점검일 정해 실제로 한 번 점검하고 기록
- [ ] Benchmark Compare / 내 수익률을 벤치마크 지수와 비교해 초과·미달 기록
- [ ] Policy Update Log / 원칙을 바꿀 때 사유와 날짜를 남기는 기록 시작
