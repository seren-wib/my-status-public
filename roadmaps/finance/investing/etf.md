# ETF `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-26

## 1. Product Structure

- [ ] Prospectus Read / 내가 살 ETF의 투자설명서에서 기초지수·운용방식 확인해 정리
- [ ] Physical and Synthetic / 실물복제·합성복제 ETF를 하나씩 찾아 차이를 표로 정리
- [ ] Holdings Check / 보유 ETF의 구성종목 상위 10개와 비중 조회해 기록
- [ ] Distribution Policy `택 1` / 분배금 지급형, 토탈리턴형

## 2. Cost and Tracking

- [ ] Expense Ratio Compare / 같은 지수를 따르는 ETF 3개의 총보수·실부담비용 비교표 작성
- [ ] Tracking Error Check / 내가 사는 ETF의 추적오차 조회해 기록
- [ ] Premium Discount Watch / 장중 괴리율을 며칠 관찰해 매수 시점 판단
- [ ] Spread and Slippage / 호가 스프레드 확인하고 소액 체결로 실제 슬리피지 측정

## 3. Tax and Account

- [ ] Domestic and Overseas Tax / 국내상장 해외ETF와 해외상장 ETF의 세금을 내 투자금 대입해 계산 비교
- [ ] ISA Setup / ISA 계좌 개설하고 유형 골라 첫 매수 실행
- [ ] ISA Limit Track / 내 납입한도·의무보유 기간을 조회해 관리표로 기록

## 4. Automation

- [ ] Auto Buy Order / 적립식 자동매수 설정하고 첫 자동 체결 확인
- [ ] Contribution Schedule / 월 적립액과 매수일을 정해 3개월 실행
- [ ] Distribution Reinvest / 받은 분배금을 재투자까지 처리하고 금액 기록
