# Stocks `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-26

## 1. Reading Disclosures

- [ ] Annual Report Read / 관심 기업 사업보고서 한 편 읽고 사업·위험 요약 한 장
- [ ] Disclosure Alert / 공시 알림 걸어두고 한 달간 뜬 공시 3건을 해석해 기록
- [ ] Dilution Factors / 최대주주 지분과 전환사채 등 희석 요인 조회해 정리
- [ ] Earnings Note / 실적발표 자료 하나 보고 회사 전망과 실제 결과의 차이 기록

## 2. Business Model

- [ ] Revenue Breakdown / 매출을 사업부·지역별로 쪼개 표로 정리
- [ ] Competitor Compare / 같은 산업 3개 기업의 점유율·마진 비교표 작성
- [ ] Moat Statement / 이 기업이 왜 안 무너지는지 한 문단으로 써보기

## 3. Valuation

- [ ] Multiple Calc / 관심 종목의 PER·PBR·ROE를 최신 재무로 직접 계산
- [ ] Peer Multiple Band / 동종 기업 5개 배수와 비교해 고평가·저평가 판단 기록
- [ ] Dividend Check / 배당수익률·배당성향 계산하고 지속 가능성 판단
- [ ] Simple DCF / 단순 가정으로 현금흐름 할인해 적정가 한 번 산출

## 4. Decision and Record

- [ ] One-page Thesis / 한 종목 분석 리포트 한 장 작성하고 목표가·근거 명시
- [ ] Buy Execution / 리포트에 쓴 근거대로 실제 매수 실행하고 체결 기록
- [ ] Sell Criteria / 매도할 조건을 미리 문장으로 못 박고 위반 시 실행
- [ ] Thesis Review / 3개월 뒤 가정이 맞았는지 다시 써서 처음 리포트와 비교
