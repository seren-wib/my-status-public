# Financial Statements `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-26

## 1. Getting the Filings

- [ ] Pick One Company / 상장기업 하나 골라 최근 사업보고서 원문 내려받기
- [ ] Statement Locate / 사업보고서에서 손익계산서·재무상태표·현금흐름표 위치를 찾아 표시
- [ ] Notes Cross-check / 주석에서 매출 구성이나 차입금 조건 하나를 찾아 본표 숫자와 연결

## 2. Reading the Three Statements

- [ ] Income Statement Walk / 매출부터 당기순이익까지 무엇이 단계마다 빠지는지 한 장 요약
- [ ] Balance Sheet Split / 자산·부채·자본을 항목별로 나눠 큰 덩어리 셋 짚어내기
- [ ] Cash Flow Three Ways / 영업·투자·재무 현금흐름의 부호 조합을 읽고 회사 상태 한 줄로 진단
- [ ] Statements Linked / 순이익이 자본 항목과 현금흐름표 첫 줄로 어떻게 이어지는지 직접 추적

## 3. Quality of Earnings

- [ ] Profit Versus Cash / 당기순이익과 영업현금흐름 차이를 계산하고 원인 항목 찾기
- [ ] Receivables Trend / 매출채권·재고 증가율을 매출 증가율과 나란히 놓고 표로 정리
- [ ] One-off Items / 일회성 이익·손실을 걷어낸 조정 이익 직접 계산

## 4. Ratios by Hand

- [ ] ROE Decomposition / ROE를 순이익률·자산회전율·레버리지로 분해해 계산
- [ ] Debt and Liquidity / 부채비율·유동비율 직접 계산하고 업종 평균과 비교
- [ ] Margin Trend / 3개년 영업이익률을 계산해 추세 한 장으로 정리

## 5. Comparing Two

- [ ] Two Company Table / 같은 업종 두 기업의 비율을 한 표에 놓고 차이 설명
- [ ] Red Flag Hunt / 한 기업에서 의심 신호 3개를 근거와 함께 적기
