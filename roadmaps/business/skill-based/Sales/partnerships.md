# Partnerships `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. Finding Partners

- [ ] Complement Map / 내 고객을 이미 갖고 있는 업체 유형을 그려 후보군 정의
- [ ] Partner Candidate List / 제휴 후보 20곳을 담당자·접점까지 채운 표로 만들기
- [ ] Value Exchange Sheet / 후보 5곳별로 내가 주는 것과 받을 것을 한 줄씩 적기

## 2. Making the Approach

- [ ] Partnership Pitch / 상대 이익을 앞세운 제휴 제안서 한 장 만들기
- [ ] Outreach Batch / 후보 10곳에 제휴 제안 발송하고 응답 기록
- [ ] Pilot Proposal / 한 곳과 기간·범위를 좁힌 소규모 파일럿 합의 도출

## 3. Channel Structure

- [ ] Reseller Terms / 리셀러 마진·최소물량·지원 범위를 정한 조건표 만들기
- [ ] Affiliate Setup / 어필리에이트 링크·추적·정산 구조를 만들어 1명 등록시키기
- [ ] Partner Enablement Kit / 소개 자료·데모·FAQ를 묶어 파트너에게 전달
- [ ] Referral Fee Rule / 소개 수수료 지급 기준을 문서화하고 1건 실제 정산

## 4. Running and Reviewing

- [ ] Live Partnership / 제휴 하나를 실제로 굴려 첫 매출이나 첫 리드 발생시키기
- [ ] Attribution Tracking / 파트너별 유입·전환을 구분해 기록하는 표 운영
- [ ] Quarterly Partner Review / 분기 단위로 성과를 점검하고 조건 재협상 또는 종료
- [ ] Exit Clause Test / 성과 없는 제휴 하나를 관계 상하지 않게 정리하기
