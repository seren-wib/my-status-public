## 2. Scope Defense

- [ ] Scope Document / 포함·불포함·수정 횟수를 못 박은 스코프 문서 한 장 쓰기
- [ ] Change Request Flow / 스코프 밖 요구를 추가 견적으로 되돌리는 절차 만들고 1건 적용
- [ ] Saying No in Writing / 무리한 요구 하나를 근거와 대안을 붙여 서면으로 거절
- [ ] Revision Log / 한 프로젝트의 수정 요청을 전부 기록해 초과분 청구하기

## 3. Delivery and Communication

- [ ] Kickoff Pack / 착수 시점에 일정·연락 창구·산출물을 정리해 고객에게 전달
- [ ] Progress Report / 정해진 주기로 진행 보고를 2회 이상 실제 발송
- [ ] Bad News Early / 지연이나 문제를 터지기 전에 먼저 알리고 대안 제시한 사례 1건
- [ ] Handover and Sign-off / 산출물 인수인계 후 완료 확인을 서면으로 받기

## 4. Retention and Referral

- [ ] Payment Discipline / 계약금·잔금 일정을 걸고 미수금 하나를 실제로 회수
- [ ] Renewal Pitch / 종료된 건 하나에 다음 단계 제안을 먼저 보내기
- [ ] Referral Request / 만족한 고객에게 소개를 요청해 새 리드 1건 확보
- [ ] Case Study Write-up / 끝난 프로젝트를 문제·과정·결과로 정리해 공개용 한 편
- [ ] Client Health Check / 고객별 매출·손이 가는 정도를 표로 정리하고 손절 후보 고르기
