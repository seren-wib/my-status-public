# Sales Process `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. Lead Sourcing

- [ ] Ideal Customer Sheet / 지금까지 만난 고객을 업종·규모·예산으로 정리해 한 줄 정의 쓰기
- [ ] Lead List Build / 조건에 맞는 잠재 고객 30곳을 담당자·연락처까지 채운 표로 만들기
- [ ] Sourcing Channels / 커뮤니티·전시회·공고 사이트 등 리드가 나오는 경로 3개를 직접 뚫어보기
- [ ] Lead Scoring / 만든 리스트를 확률 기준으로 A·B·C 등급 매겨 상위 10곳 추리기

## 2. Outreach

- [ ] Cold Outreach Batch / 잠재 고객 10곳에 첫 메일 보내고 응답률 기록
- [ ] Message Variants / 제목·첫 문장만 바꾼 두 버전을 각 10통 보내 응답 차이 비교
- [ ] Follow-up Sequence / 무응답 건에 간격을 두고 3회까지 후속 연락하고 결과 남기기
- [ ] Referral Ask / 기존 지인·고객 5명에게 소개를 요청해 실제 소개 1건 받기

## 3. Pipeline Operation

- [ ] Stage Definition / 접촉·미팅·제안·협상·성사 단계를 내 사업 기준으로 정의해 문서화
- [ ] Pipeline Board / 진행 중인 건을 단계별로 올린 표를 만들고 2주간 매일 갱신
- [ ] Weekly Pipeline Review / 주 1회 전체 건을 훑고 죽은 건을 실제로 닫아 정리하기
- [ ] Next-Step Discipline / 모든 진행 건에 날짜 박힌 다음 액션이 하나씩 있게 만들기

## 4. Deal Cycle

- [ ] Discovery Call / 고객 미팅에서 예산·결정권자·일정을 확인해 메모로 남기기
- [ ] Buying Process Map / 한 건에서 결재선과 도장 찍히기까지 단계를 그림으로 그리기
- [ ] Loss Post-Mortem / 놓친 건 3개의 실제 사유를 확인해 기록하고 패턴 뽑기
- [ ] Cycle Metrics / 첫 접촉부터 계약까지 걸린 기간과 전환율을 실제 수치로 계산
