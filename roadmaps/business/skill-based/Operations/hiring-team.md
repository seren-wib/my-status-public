# Hiring and Team `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. Defining the Role

- [ ] Work to Offload / 내 업무 목록에서 넘길 일을 골라 한 사람 몫으로 묶기
- [ ] Job Description / 성과 기준까지 적힌 JD 한 편 써서 실제 게시
- [ ] Compensation Range / 시장 시세를 조사해 급여 범위와 근거를 문서로 확정
- [ ] Employment Form `택 1` / 정규직, 계약직, 프리랜서 외주

## 2. Sourcing and Screening

- [ ] Channel Posting / 채용 채널 2곳 이상에 공고를 올려 지원자 받기
- [ ] Screening Rubric / 서류를 점수화하는 기준표 만들어 지원자 전부 채점
- [ ] Work Sample Task / 실무와 같은 과제를 만들어 후보에게 내고 결과 평가

## 3. Interviewing

- [ ] Structured Question Set / 모든 후보에게 같은 질문을 하도록 질문지 고정
- [ ] Behavioral Probe / 과거 사례를 상황·행동·결과로 캐묻는 면접 1회 진행
- [ ] Reference Check / 전 동료나 상사에게 실제로 평판 조회 1건 수행
- [ ] Offer and Contract / 처우를 문서로 제시하고 근로계약서까지 체결

## 4. Delegation and Onboarding

- [ ] First Delegation / 업무 하나를 권한까지 넘기고 내가 손대지 않고 끝내게 하기
- [ ] Onboarding Plan / 첫 2주 일정과 첫 성과물을 정한 온보딩 문서 만들어 실행
- [ ] Decision Boundary / 혼자 정해도 되는 것과 물어봐야 하는 것을 선 그어 문서화
- [ ] Handover Doc / 넘긴 업무의 절차·계정·연락처를 인수인계 문서로 정리

## 5. Running the Team

- [ ] Weekly One-on-One / 1:1을 4주 연속 진행하고 매회 액션 아이템 남기기
- [ ] Feedback Delivered / 고칠 점 하나를 사실·영향·요청 형태로 직접 전달
- [ ] Performance Review / 정해둔 성과 기준으로 평가 1회 하고 결과 서면 전달
- [ ] Exit Handling / 퇴사 또는 계약 종료 1건을 인수인계·정산까지 마무리
