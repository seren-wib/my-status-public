# Operations `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. Mapping the Work

- [ ] Time Audit / 2주간 실제 업무 시간을 기록해 어디로 새는지 표로 뽑기
- [ ] Repeating Task List / 매주 반복되는 업무를 전부 적어 빈도·소요시간 붙이기
- [ ] SOP Write-up / 반복 업무 3개를 남이 따라 할 수 있는 절차서로 작성
- [ ] Bottleneck Pick / 가장 오래 걸리는 공정 하나를 골라 개선 목표 수치 정하기

## 2. Automation

- [ ] Checklist Before Tool / 자동화 전에 수작업 체크리스트로 두 번 돌려보기
- [ ] Template and Snippet / 자주 쓰는 문서·메일을 템플릿으로 만들어 실사용
- [ ] Workflow Automation / 반복 업무 하나를 자동화해 손 대는 횟수 0으로 만들기
- [ ] Automation Failure Plan / 자동화가 멈췄을 때 알림과 수동 대체 경로 만들어두기

## 3. Outsourcing

- [ ] Task Spec for Outsourcing / 외주 줄 업무 하나를 산출물·기준·마감으로 명세화
- [ ] First Hire-out / 외주 1건을 실제로 발주해 결과물 받아보기
- [ ] Quality Gate / 외주 결과를 통과·반려로 판정하는 기준표 만들어 적용
- [ ] Vendor Comparison / 같은 업무를 두 곳에 맡겨 단가·품질·속도 비교 기록

## 4. Tools and Records

- [ ] Tool Stack Sheet / 쓰는 도구·비용·용도를 한 표로 정리하고 중복 해지
- [ ] Single Source Rule / 흩어진 문서를 한 곳으로 모으고 폴더 규칙 문서화
- [ ] Access and Backup / 계정 권한을 정리하고 핵심 데이터 백업을 복구까지 테스트

## 5. Customer Support

- [ ] Inquiry Log / 들어온 문의를 유형별로 분류해 한 달치 집계
- [ ] Canned Responses / 자주 나오는 문의 5개에 표준 답변 만들어 실제 사용
- [ ] Response SLA / 응답 시간 목표를 정하고 2주간 지켰는지 기록
- [ ] Complaint to Fix / 반복 불만 하나를 제품이나 절차 수정으로 없애기
