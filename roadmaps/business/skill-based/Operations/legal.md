# Legal `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. Setting Up the Entity

- [ ] Business Registration / 사업자등록 직접 완료하고 등록증 받기
- [ ] Entity Form Choice `택 1` / 개인사업자, 법인
- [ ] Online Sales Filing / 통신판매업 신고 또는 면제 요건 확인해 처리
- [ ] Licenses Check / 내 업종에 필요한 인허가·신고 항목을 확인해 목록으로 정리

## 2. Contracts

- [ ] Standard Template / 표준계약서를 내 사업에 맞게 고쳐 내 계약서 한 부 만들기
- [ ] Red-flag Review / 남의 계약서 샘플 하나에서 독소조항 3개 찾아 표시
- [ ] Clause Negotiation / 받은 계약서에서 조항 하나를 실제로 수정 요청해 반영시키기
- [ ] Signed Contract / 전자계약이나 날인으로 계약 1건 체결하고 보관 체계 만들기
- [ ] Confidentiality and IP Terms / 비밀유지·저작권 귀속 조항을 내 계약서에 직접 써넣기

## 3. Policies and Data

- [ ] Terms of Service / 내 서비스 이용약관을 작성해 실제로 게시
- [ ] Privacy Policy / 수집 항목·보유 기간·위탁을 채운 개인정보처리방침 게시
- [ ] Consent Flow / 가입·문의 화면에 동의 절차를 실제로 붙이기
- [ ] Data Inventory / 어떤 개인정보를 어디에 두는지 표로 정리하고 불필요분 삭제

## 4. Intellectual Property

- [ ] Trademark Search / 쓰려는 이름을 특허정보 검색으로 조회해 충돌 여부 확인
- [ ] Trademark Filing / 상표 출원 실제 접수하고 출원번호 받기
- [ ] License Audit / 쓰는 폰트·이미지·오픈소스의 라이선스를 점검해 위반 건 정리
- [ ] Infringement Response / 무단 사용 사례 하나에 경고 또는 신고 절차 밟아보기
