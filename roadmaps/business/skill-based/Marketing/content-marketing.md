# Content Marketing `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. Channel and Cadence

- [ ] Primary Channel `택 1` / 뉴스레터, 블로그, X, 인스타그램, 유튜브
- [ ] Publishing Cadence / 주 몇 회 낼지 정하고 8주 발행 일정 확정
- [ ] Topic Pillars / 반복해 다룰 주제 축 3개 정하기

## 2. Production Routine

- [ ] Idea Backlog / 소재 30개 목록 만들고 상시 채워두기
- [ ] Twelve Published Pieces / 실제로 12편 발행 완료
- [ ] Batch Production Day / 하루에 4편 몰아 만들어 예약 발행
- [ ] Repurposing Chain / 긴 글 한 편을 짧은 포스트 5개로 잘라 재발행

## 3. Newsletter

- [ ] First Hundred Subscribers / 구독자 100명까지 실제로 모으기
- [ ] Welcome Email / 가입 직후 자동 발송 메일 한 통 세팅
- [ ] Open Rate Baseline / 10회 발송해 오픈·클릭 평균 기록

## 4. Social Operation

- [ ] Daily Posting Streak / 30일 연속 발행 완주
- [ ] Reply Routine / 댓글·DM에 하루 15분 답하기 4주 유지
- [ ] Collaboration Post / 다른 계정과 합작 콘텐츠 1건 발행

## 5. Growth Check

- [ ] Top Performer Autopsy / 반응 좋은 3편의 공통점 뽑아 다음 편에 반영
- [ ] Channel Kill Decision / 8주 성과로 채널 유지·폐기 결론 한 장
