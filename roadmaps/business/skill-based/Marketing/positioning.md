# Positioning `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. Target

- [ ] Best Customer Profile / 가장 잘 맞는 고객 한 명을 실제 사례로 적기
- [ ] Exclusion List / 팔지 않을 대상을 명시적으로 세 줄 적기
- [ ] Segment Pick / 후보 세그먼트 3개 중 하나만 고르고 이유 남기기

## 2. Alternatives

- [ ] Real Alternative Map / 고객이 지금 대신 쓰는 것 5개 적기
- [ ] Differentiator Proof / 남들이 못 하는 점 하나를 증거와 함께 적기
- [ ] Category Choice / 어느 범주로 불릴지 정하고 페이지 제목에 반영

## 3. The Statement

- [ ] One-Sentence Positioning / 누구를 위한 무엇이며 무엇과 다른지 한 문장으로
- [ ] Three Positioning Drafts / 완전히 다른 포지션 3안 써서 나란히 비교
- [ ] Elevator Pitch / 30초 구두 소개 만들어 5명 앞에서 말해보기

## 4. Message Testing

- [ ] Five-Second Test / 랜딩 5초만 보여주고 뭐 하는 건지 10명에게 되묻기
- [ ] Message A/B / 두 메시지를 같은 트래픽에 걸어 반응 비교
- [ ] Rejection Interview / 사지 않은 사람 5명에게 안 산 이유 듣기

## 5. Consistency

- [ ] Touchpoint Audit / 랜딩·SNS·소개서 문구가 한 포지션인지 대조 점검
- [ ] Repositioning Round / 검증 결과로 포지션 한 번 갈아엎고 전면 반영
