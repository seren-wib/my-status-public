# Paid Acquisition `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. First Campaign

- [ ] Ad Platform `택 1` / Meta, Google, X, 네이버
- [ ] Conversion Tracking Setup / 전환 추적 심고 테스트 결제로 신호 확인
- [ ] Small Budget Launch / 소액 예산으로 실제 캠페인 하나 집행

## 2. Creative Testing

- [ ] Five Ad Variants / 소재 5개 만들어 동시 집행하고 성과 비교
- [ ] Hook Rewrite / 성과 낮은 소재의 첫 3초·첫 줄만 바꿔 재집행
- [ ] Format Test / 이미지와 영상을 같은 예산으로 붙여 비교

## 3. Targeting and Budget

- [ ] Audience Split Test / 다른 타겟 두 개에 같은 소재 집행해 비교
- [ ] Retargeting Set / 방문자 리타게팅 캠페인 한 번 돌려보기
- [ ] Budget Ramp / 성과 난 세트만 예산 두 배로 올려 유지되는지 확인

## 4. Unit Economics

- [ ] Cost per Acquisition / 실제 집행으로 고객 1명 획득 단가 산출
- [ ] Payback Calculation / 광고비 회수 기간 계산해 한 줄 결론
- [ ] Breakeven Ceiling / 흑자가 유지되는 최대 입찰가를 숫자로 확정

## 5. Scale or Stop

- [ ] Kill Rule / 며칠·얼마에서 끌지 규칙 미리 적고 그대로 지키기
- [ ] Fatigue Response / 성과 꺾인 소재 교체하고 회복 여부 기록
- [ ] Spend Review Memo / 한 달 집행 결과로 계속·중단 결론 한 장
