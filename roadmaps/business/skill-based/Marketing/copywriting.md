# Copywriting `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. Headlines

- [ ] Headline Variants / 같은 제품에 헤드라인 10개 써서 지인 테스트
- [ ] Benefit over Feature / 기능 목록 5줄을 결과 문장 5줄로 다시 쓰기
- [ ] Specificity Pass / 형용사를 숫자·고유명사로 바꿔 전면 재작성

## 2. Landing Copy

- [ ] Above the Fold Set / 첫 화면 헤드라인·부제·버튼 문구 한 벌 작성
- [ ] Proof Block / 후기·수치·사례를 실제 문구로 배치
- [ ] Objection Rebuttal / 예상 거절 사유 5개에 답하는 문단 쓰기

## 3. Sales Page

- [ ] Long Form Page / 판매 페이지 전문을 처음부터 끝까지 한 편 쓰기
- [ ] Offer Statement / 무엇을 받는지 한 블록으로 못박아 쓰기
- [ ] Call to Action Variants / 버튼·마무리 문구 5안 써서 실제로 붙여보기

## 4. Email

- [ ] Subject Line Batch / 같은 메일에 제목 10개 써서 오픈률 비교
- [ ] Launch Sequence / 3~5통짜리 발송 시퀀스 작성해 실제 발송
- [ ] Plain Text Rewrite / 꾸민 메일을 맨 텍스트로 다시 써서 반응 비교

## 5. Editing

- [ ] Read Aloud Cut / 소리내어 읽고 걸리는 문장 전부 잘라내기
- [ ] Half Length Rewrite / 카피 길이를 절반으로 줄여 다시 쓰기
- [ ] Swipe Teardown / 잘 팔린 카피 3편을 구조 단위로 해부해 표로
