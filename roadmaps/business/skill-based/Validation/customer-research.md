# Customer Research `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. Finding People

- [ ] Target Segment Draft / 만나려는 사람을 직업·상황으로 한 줄 정의
- [ ] Recruiting Ten Strangers / 지인 아닌 잠재 고객 10명 섭외해 약속 잡기
- [ ] Interview Guide / 열린 질문 10개짜리 인터뷰 가이드 한 장 작성

## 2. The Interview

- [ ] First Live Interview / 실제 잠재 고객 1명과 30분 인터뷰 완주
- [ ] Five Customer Interviews / 5명 인터뷰하고 각 녹취·메모 남기기
- [ ] Past Behavior Questions / 의견 대신 최근 실제 행동만 캐묻는 세션 한 건
- [ ] Solution Talk Ban / 내 아이디어를 한 번도 꺼내지 않고 인터뷰 한 건 끝내기

## 3. Pain Extraction

- [ ] Workaround Hunt / 지금 쓰는 임시방편·엑셀 파일 실물 보여달라 요청
- [ ] Money and Time Spent / 그 문제에 이미 쓰는 돈·시간을 숫자로 받아내기
- [ ] Failed Alternatives / 써보고 버린 대안과 버린 이유 3개 수집

## 4. Synthesis

- [ ] Pain Pattern Board / 인터뷰 10건에서 반복 페인 3개 추려 한 장으로
- [ ] Verbatim Quote Bank / 고객이 쓴 표현 그대로 20개 모아두기
- [ ] Segment Split / 반응이 갈린 지점으로 대상을 두 세그먼트로 쪼개기
- [ ] Kill or Continue Memo / 인터뷰 결과로 계속·중단 결론 한 장 쓰기
