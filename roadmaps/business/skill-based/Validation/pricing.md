# Pricing `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. First Price

- [ ] Cost Floor / 원가·투입 시간 계산해 밑바닥 가격 한 줄로 확정
- [ ] Competitor Price Sheet / 경쟁 제품 5개의 가격·포함 범위 표로 정리
- [ ] Willingness to Pay Ask / 잠재 고객 10명에게 얼마면 살지 직접 물어보기

## 2. Packaging

- [ ] Three Tier Menu / 단일 상품을 3단 플랜으로 쪼개 페이지에 올리기
- [ ] Anchor Option / 비싼 상위 플랜 하나 붙이고 선택 분포 변화 관찰
- [ ] Billing Period Choice `택 1` / 월 구독, 연 구독, 1회 결제

## 3. Price Experiments

- [ ] Live Price A/B / 실제 트래픽에 두 가격 노출해 2주 매출 비교
- [ ] Discount Test / 할인 한 번 걸고 매출·마진 변화 기록
- [ ] Price Objection Log / "비싸다"는 반응 10건 원문 그대로 모으기

## 4. Raising Price

- [ ] Twenty Percent Raise / 가격 20퍼센트 올리고 전환율 변화 측정
- [ ] Grandfathering Plan / 기존 고객 유예 정책 정하고 공지 발송
- [ ] Churn After Raise / 인상 후 이탈률 한 달 추적해 유지·되돌림 결정

## 5. Freelance Rates

- [ ] Hourly Floor / 목표 연수입에서 역산해 최저 시급 산출
- [ ] Fixed Bid Quote / 실제 문의 한 건에 범위 견적서 작성해 발송
- [ ] Scope Change Clause / 추가 요청 시 추가 과금 조항 넣어 견적 재발송
