# Market Testing `AI 생성`

> AI가 작성한 로드맵 · roadmap.sh 원본 아님 · 2026-08-25

## 1. Smoke Test

- [ ] Landing Page Live / 도메인 걸고 랜딩 한 장 실제 배포
- [ ] Waitlist Capture / 이메일 수집 폼 붙여 첫 신청 10건 받기
- [ ] Traffic Injection / 커뮤니티·광고로 방문자 300명 실제로 태우기

## 2. Demand Signals

- [ ] Fake Door Test / 아직 없는 기능 버튼 달고 클릭률 1주 측정
- [ ] Concierge Delivery / 자동화 없이 손으로 5명에게 직접 서비스 제공
- [ ] Signal Threshold / 시작 전에 합격선 숫자를 적어두고 결과와 대조

## 3. Preselling

- [ ] First Paid Preorder / 만들기 전에 선결제 1건 받아내기
- [ ] Deposit Ask / 무료 관심자에게 보증금 요청해 진짜 수요만 남기기
- [ ] Refund Promise Test / 환불 조건 걸고 팔아 실제 환불률 확인

## 4. MVP Round

- [ ] Two-Week MVP / 2주 안에 쓸 수 있는 최소 버전 하나 출시
- [ ] Ten Real Users / 실사용자 10명에게 붙여 사용 기록 남기기
- [ ] Manual Backend / 자동화 대신 사람이 처리하는 채로 2주 운영

## 5. Decision

- [ ] Pivot or Persevere Memo / 실험 결과로 방향 유지·전환 결론 한 장
- [ ] Killed Experiment Log / 접은 실험과 접은 이유 5건 기록
